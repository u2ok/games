# 飞机大战

原生 HTML、CSS、JavaScript 自动射击生存游戏，直接打开 `index.html` 或静态托管即可运行。无构建工具、ES6 Modules、远程图片或音频依赖。

## 操作与规则

- 方向键/WASD 移动；鼠标移入画布跟随移动；手机按住画布拖动战机，按下时不跳位置。自动向上射击。
- 空格开始、暂停或继续；也可使用统一按钮。打开菜单、设置、页面失焦时暂停，手动继续。
- 普通敌机 1 点耐久，击毁 +10 分；每第五架为重型机，3 点耐久，击毁 +30 分。
- 初始 3 条生命，碰敌机或敌弹损失一条，随后 1.6 秒无敌并清除敌弹。敌机飞出屏幕不扣命、不得分。
- 敌机随生存时间逐渐加速、生成加快，有上限。三条生命耗尽后结束，显示得分和生存时间。

## 道具与火力

道具以带字方块缓慢下落，接触即可拾取。开局 6 秒开始补给，此后每 12 秒投放；每击毁 4 架敌机或击毁重型机也会掉落。同屏最多 6 个，掉出屏幕消失。道具按火、散、速、穿、修、直顺序轮转，暂停时停止下落与倒计时。

| 标记 | 效果 |
| --- | --- |
| 火 | 火力提升一级，最高 3 级，受击降低一级，最低 1 级 |
| 散 | 切换散射，随火力等级发射 3/5/7 发扇形弹 |
| 穿 | 切换贯穿，1/2/3 条弹道，单弹伤害 2/3/4，可穿过多架敌机，同一弹不重复伤害同一目标 |
| 直 | 切换直射，1/2/3 条弹道，3 级单弹伤害提升为 2 |
| 速 | 8 秒双倍射速，可叠加剩余时间至最多 20 秒 |
| 修 | 恢复一条生命，最多 3 条；已满时转为 50 分 |

切换子弹保留火力等级，武器持续到再次拾取其他子弹或重开。画布左上角显示当前武器、火力和速射剩余时间。结束后不能通过维修复活，新一局重置全部效果。道具版纪录与旧版分开保存，旧纪录不会被覆盖。

## 设置与记录（道具版）

轻松、标准、挑战三档，默认为标准，修改难度在新一局生效；最佳成绩按难度分别保存。音效默认关闭，用 Web Audio 合成。设置和纪录仅保存在本机，存储受限时回退内存并提示。当前局不跨刷新恢复。

## 实现与适配

600×600 逻辑画布，固定 1/120 秒小步长更新，限制单帧累计时间避免恢复时突然跳跃。暂停清除按键和拖动状态。

`base.css`、`interface.js` 为随游戏保存的统一基础；`style.css` 为画布专属样式，`script.js` 为独立闭包逻辑。复制整个文件夹可独立运行，返回大厅链接需按位置调整。手机通过直接拖动画布操作，不额外占用方向键区域。



## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，局内操作保留在游戏区下方。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`base.css`、`interface.js` 为公共源的独立副本，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；复制目录独立运行不依赖这些文档链接。
