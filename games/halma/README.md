# 跳棋

六角星形中国跳棋，双边对弈，每方十枚棋子。直接打开 `index.html`，无构建工具、ES6 Modules、外部资源或网络依赖。

## 规则

红方先行，红棋起始于下营、目标为上营；蓝棋相反。每回合选择一枚己方棋子：

- 移到相邻空孔，回合立即结束。
- 跳过六个方向之一的相邻棋子，落到其后的空孔；中间可为任意颜色，不移除棋子。
- 可使用同一棋子变向连续跳跃，不能重复落到本回合已经访问的孔。继续点击提示落点，或点“结束回合”主动停止；没有后续跳法时自动结束。
- 全部十枚先到对面营地的一方胜。进入目标营地后不得跳出，可在营内调整。
- 只有无合法移动时才能跳过回合；同一棋子布局与行动方出现三次判和。

另外四个营地可通行。本版本没有多色多人、长跳（跨多个空孔）、捕获或竞赛反堵营裁定。

## 操作与电脑

点击或触屏选棋，再点击合法落点；未开始连跳时再次点击选中棋子可取消。实心绿点表示移步，空心绿环表示下一跳。选择棋子后点击“路线提示”，显示带编号的虚线跳路，请逐孔点击；提示不会自动落子。键盘聚焦棋盘后使用方向键移动孔位光标，Enter/空格确认。

电脑分为轻松、标准、挑战，在设置中切换，新一局生效。轻松侧重向前推进；标准使用最小距离分配，为十枚棋子分别规划不同目标孔，并考虑离营、归位及重复局面；挑战在部分优选走法上评估对手应手。近优走法随机选择，避免固定棋路。搜索限制候选数量及时间预算，不保证最优解，复杂局面可能有短暂计算延迟。

人机你执红；本机双人红蓝轮流。人机悔棋撤回最近一轮，电脑尚未走时只撤回己方一步；连跳中悔棋只撤销当前连跳。本机双人撤回一回合，终局不可悔棋。暂停、设置、手机菜单、窗口失焦时取消电脑回调，继续后重新安排。

模式、音效、电脑难度和胜局记录保存在本机；面板显示双方当前归位数量。存储不可用时退回内存。音效默认关闭。

## 独立资源

`../../shared/base.css`、`../../shared/interface.js` 是统一基础副本，`style.css` 定义工具栏，`script.js` 包含121孔坐标、营地、移步、连续跳跃、电脑与绘制。复制目录可独立运行，返回大厅地址按目标目录调整。

Canvas 提供键盘输入和状态文字，但不提供完整读屏棋盘。历史浏览器抽查见合集测试报告；不代表当前版本所有状态或真实设备均已验收。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`../../shared/base.css`、`../../shared/interface.js` 直接引用根目录公共源，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；仅复制本目录不能完整运行，需携带shared公共文件并保留相对路径。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。公共布局直接维护shared/base.css，玩法私有样式维护本目录style.css；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
