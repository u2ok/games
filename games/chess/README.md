# 国际象棋

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 玩法

白先黑后，点选棋子再选目标格；方向键选格，Enter走棋。支持将军/应将、将死、逼和、王车易位（王与车未动、路径不受攻击）、吃过路兵（紧接对手兵双步）、兵升变后/车/象/马。升变种类在配置中选择，默认后。五十回合未动兵或吃子、同一局面三次重复及不足将死子力自动和棋，采用自动结算变体而非申请和棋。人机执白，三档随机/两层/三层有限搜索，250/650毫秒及节点预算，不保证最佳；双人同屏。悔棋在终局前可用，人机撤回一轮；棋子为本地SVG。

## 操作与设置

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

## 数据与资源

本机localStorage保存设置与对战模式，不保存进行中的棋局，失败回退当前页内存，不上传数据。script.js为独立规则；style.css只维护棋盘；logo.svg为本地SVG物件图形；../../game-base.css、../../game-interface.js、../../game-icons.js由页面直接引用根公共源。

## 已知范围与限制

同一局面三次重复、五十回合规则采用自动和棋变体，无申请流程。电脑为有限预算搜索，不含联网、开局库、残局库。升变偏好立即生效并保存，难度下一局生效。

## 验证范围

模拟DOM规则回归与浏览器视口模拟证据见根TEST-REPORT.md；不等同真机或全部对局通关。


## 棋盘与提示

木质边框、浅米/灰绿格面；六种棋子使用本地SVG独立轮廓、象牙白/深石墨渐变与轻阴影。棋盘边缘保留a–h、1–8坐标。选中为蓝框，空格可走点为圆点，可吃子为暖色环，上一手起终点为浅金色，将军为红色提示；屏幕阅读标签同步说明可走/可吃子/将军。落子有轻量过渡，遵循系统减少动态效果偏好。导航、模式设置、信息卡与操作栏采用公共布局。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
