# 水排序

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 玩法

每管容量4。先选源管，再选空管或顶层同色的目标管，一次尽量倒出连续同色液体。所有非空管装满且各自单色获胜。20关使用可逆洗牌生成可解题；提示局不计最少步数。方向键选管，Enter操作；撤销不改变题目。提示搜索限50000状态，超限可撤销或重开。

## 操作与设置

试管使用玻璃质感，连续同色合并为液层，同时保留数字标识。选管时抬起；合法倒水会倾斜试管、显示水流与水平液面，目标液位随注入升高。动画约1.1秒，完成后才记录一步；期间不接受新的倒水、撤销或提示，暂停会冻结并可继续，重开/切关会清理未完成动作。系统启用“减少动态效果”时直接完成倒水。

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

## 数据与资源

本机localStorage保存设置、关卡解锁和分难度/分关纪录，失败回退当前页内存，不上传数据。script.js为独立规则；style.css只维护棋盘；logo.svg为本地SVG物件图形；base.css、interface.js、icons.js由根公共源同步。

## 已知范围与限制

三档分别3/5/7色；20关是递增扰乱深度的随机局面，并非20张固定关卡。提示搜索有节点预算，可能提示暂未找到路线。
