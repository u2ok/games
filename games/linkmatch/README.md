# 连连看

直接打开本目录 `index.html` 或静态托管即可运行，无构建工具、ES6 Modules 或网络依赖。

## 玩法

依次选择两个相同图案，若路径经过空格且最多转弯两次即可消除。路径可以绕行棋盘外侧的一圈空白，不能穿过其他图案。再次点击当前图案取消选择，无法配对时改为选择后点击的图案。清空棋盘即完成。

轻松 6×6，标准 8×8，挑战 10×10；默认标准，修改难度在新一局生效。首次选择、提示或洗牌开始计时；暂停、设置、手机菜单、页面失焦期间不计时。

## 提示与重排

提示标出一对可连接的图案并画出路线；洗牌重新排列剩余图案，保留空格位置和已消除进度。两者不限次数，界面统计使用次数。当前没有可消除配对时自动重排，不计手动洗牌次数。

打乱会有限重试，必要时将同图案换到可连通的位置，确保至少一对可消除。后续每次消除都检查死局并自动修复；不宣称初始布局无需洗牌就能全部消除。

## 记录与实现

最快完成秒数按难度分别保存，允许使用提示和洗牌，不区分辅助纪录。音效默认关闭；设置与纪录仅保存在本机，存储失败回退内存并提示。当前局不跨刷新恢复。

路径搜索在带外圈的网格中保存方向、转弯数和父节点；连接线与网格共用坐标，避免外侧绕行被裁切。连接动画和提示在暂停时冻结。

`../../shared/base.css`、`../../shared/interface.js` 为根目录共享基础入口，`style.css` 只定义棋盘和辅助按钮，`script.js` 为闭包中的完整规则。复制整个目录可独立运行，返回大厅链接应按位置调整。手机保留棋盘与提示/洗牌按钮，同一屏操作。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`../../shared/base.css`、`../../shared/interface.js` 直接引用根目录公共源，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；仅复制本目录不能完整运行，需携带shared公共文件并保留相对路径。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
