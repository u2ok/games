# 算二十四点

直接打开本目录index.html或通过静态服务器访问，无框架、构建或外部依赖。

## 规则与操作

每局四张数字牌，每张必须恰好用一次，通过加减乘除得到24。依次点两张牌，再选择运算；减法、除法按选择顺序。中间结果自动带括号，允许负数、零和分数，禁止除零、数字拼接及幂运算。重复数字是独立的牌，每局保证至少一种解法。撤销恢复上一步，不回退用时。最后结果不是24时可撤销继续尝试。

提示展示原题的一种完整解法，使用后不计最快纪录。标准1–9、进阶1–13两种范围分别保存最快纪录；设置在重开后生效。计时从首次选牌开始，暂停不计时。

## 公共功能

P暂停/继续，Enter开始/继续/再玩，Shift+Enter重新开始（重新发题）。按钮支持Tab和Enter/空格操作。打开设置、窗口失焦或隐藏自动暂停，返回后手动继续。音效默认关闭；设置与纪录本机保存，存储失败回退内存。

PC为棋盘与右侧信息面板，移动端顶部信息、中央玩法和下方操作栏，更多菜单集中模式、配置与说明。

## 文件与验证

index.html为入口；script.js包含精确有理数运算、求解与交互；style.css仅维护数字牌与必要输入；logo.svg为本地物件式标识；../../shared/base.css、../../shared/interface.js、../../shared/icons.js为公共独立副本。复制本目录即可离线运行，返回大厅链接可按需调整。

遵循[统一规范](../../GAME-STANDARD.md)，验证范围见[测试记录](../../TEST-REPORT.md)。浏览器视口模拟不能替代真机测试。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。公共布局直接维护shared/base.css，玩法私有样式维护本目录style.css；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
