# 接水管

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 玩法

点击管道顺时针旋转90度。左上水源必须从左边接入，右下出口必须向右接出；水流经过的接口都要互相接好，不能漏水，未接入水流的装饰管道可忽略。20关，三档5/6/7格及240/210/180秒。方向键选格，Enter旋转；提示指出生成路线中的未就位格，提示局不记纪录，撤销不恢复时间。

## 操作与设置

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

## 数据与资源

本机localStorage保存设置、关卡解锁和分难度/分关纪录，失败回退当前页内存，不上传数据。script.js为独立规则；style.css只维护棋盘；logo.svg为本地SVG物件图形；../../shared/base.css、../../shared/interface.js、../../shared/icons.js由页面直接引用根公共源。

## 已知范围与限制

轻松/标准/挑战分别5/6/7格、240/210/180秒；20关为随机连通路线，允许未接入水源的干管。只有通水部分需要无漏口。

## 验证范围

模拟DOM规则回归与浏览器视口模拟证据见根TEST-REPORT.md；不等同真机或全部对局通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
