# 数独

原生 HTML/CSS/JavaScript 标准 9×9 数独，直接打开 `index.html` 或静态托管即可运行，无构建工具、ES6 Modules 或外部资源。

## 规则与输入

每行、每列和每个 3×3 宫都必须包含 1–9，且不能重复。题目固定数字不可修改。选择格子后点击棋盘下方数字键，或用键盘 1–9 输入；方向键移动选择，Backspace/Delete/0 擦除，N 切换笔记，Ctrl/Cmd+Z 撤销。首次编辑开始计时，暂停不计时。

笔记用于手动记录候选数字，不判断答案。填写数字会清理同行、列、宫内的同值笔记。擦除和笔记修改均可撤销，最多保留最近 200 步，撤销不回退时间。冲突提示只检测当前行、列、宫的重复数字，不代表填入值一定是正确答案。

选中已填数字时，所有相同数字的格子以浅绿强调，包含题目数字和用户填写数字；选中格保留深绿边框，冲突格仍优先显示红色。再次点击当前格会取消选中并清除高亮；选择空格或擦除当前数字后清除同值高亮，候选笔记不参与匹配。

## 出题与难度

通过合法行列、数字置换创建完整答案，再逐个移除数字；每次删数使用最少候选优先回溯检查唯一解，最多计到两解。入门/标准/挑战目标分别为 42/34/28 个提示数，无法进一步删除时保留更多数字，以唯一解为优先；页面显示实际提示数量。难度是提示数量分档，不声称经过人工解题技巧评级。

难度下一局生效；音效默认关闭；冲突提示默认开启、立即生效。最佳完成秒数按难度分别保存，设置与成绩仅在本机，存储不可用时回退到内存。

## 独立文件与适配

`base.css` 与 `interface.js` 为统一基础副本，`style.css` 为数独专属样式，`script.js` 为封闭作用域中的出题与游戏逻辑。复制整个文件夹即可运行，返回大厅链接应按目录调整。

桌面左棋盘右面板；手机棋盘与数字键盘按剩余视口高度同时适配。打开菜单、设置、切换页面或窗口失焦时暂停，关闭后手动继续。题目与当前填写不跨刷新恢复。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，局内操作保留在游戏区下方。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`base.css`、`interface.js` 为公共源的独立副本，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；复制目录独立运行不依赖这些文档链接。
