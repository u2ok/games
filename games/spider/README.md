# 蜘蛛纸牌

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 玩法

104张牌、10列，同花K至A自动收走，收齐8组获胜。可移动牌段须全部正面、同花连续递减；目标顶部须为大一阶的正面牌，花色可不同；空列可放任意合法牌段。

| 难度 | 发牌与目标 |
|---|---|
| 入门（默认） | 单花色、104张全明牌、两列空位、无库存发牌。交换成对牌列的尾段生成题目，并验证12步通关路线，适合练习借空列整理。 |
| 经典 | 单花色，初始54张、50张库存，分5轮每列发一张。 |
| 进阶 | 双花色，使用经典发牌。 |
| 挑战 | 四花色，使用经典发牌。 |

经典及以上有空列时不能发牌，随机局不保证可解；生成时筛选可移牌的开局。入门的可通关保证针对初始局面及记录路线，自行改变路线后不承诺任意局面都可解。

初始500分，每步扣1分，每收一组加100分。提示/辅助移牌局标为“辅助局”，不记最佳成绩。首次升级到本版会进入入门模式，保留原音效与旧成绩；后续手动选项正常保存。新成绩使用v2键，与旧版难度纪录隔离。

## 操作与设置

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

点击牌段再点击目标列，蓝框显示合法落点；左右键换列，上下键选择牌，Enter操作。点击“提示”高亮源牌段和目标列，再点“按提示移牌”执行一步。记录路线可用时优先给出入门解法，否则优先收牌、翻开暗牌、同花连接，避免建议整列无意义换空位。撤销恢复完整牌列/库存/分数，也可撤销获胜一步。

牌面显示清晰点数、本地SVG花色和牌背纹理；顶部显示八组收牌进度。按牌桌实际高度分配重叠距离，背牌窄露边、正面保留点数行，手机与横屏分别检查。

## 数据与资源

本机localStorage保存设置、难度版本和分难度纪录，不保存进行中的牌局；失败回退当前页内存，不上传数据。script.js为独立规则；style.css只维护棋盘；logo.svg为本地SVG物件图形；base.css、interface.js、icons.js由根公共源同步。

## 已知范围与限制

入门是明确标注的全明牌训练变体，经典及以上保留库存和暗牌。当前支持点选、键盘选牌与执行提示，不含拖动或通用完备求解器；偏离入门记录路线后的建议为启发式，不保证最佳。手机十列保持同时可见，极长牌列仍会按空间压缩重叠。
