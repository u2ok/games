# 钓鱼游戏

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 玩法

三片湖泊逐步解锁，目标分别40、75、110分。点击“抛竿”，看浮漂明显下沉时点击“提竿”；中鱼后按住“收线”或空格，松开即放线。收线进度满格即可钓获；张力达到100，或放线过久距离超过150会脱钩。张力偏高时界面提示松开。

每局10枚鱼饵。等待时重复点击不消耗鱼饵、不取消当前抛竿。首竿才开始计时，轻松/标准/挑战分别150/125/105秒；提竿窗口3/2.4/1.8秒，首条鱼额外宽限0.5秒。达到目标后展示收鱼结果并通关，不必继续耗尽鱼饵；超时或鱼饵用完也会结算。

四类鱼为鲫鱼、鲈鱼、鳟鱼、锦鲤，分别奖励10/20/35/50分、2/3/4/5金币。三湖分别可遇到2/3/4类鱼。鱼竿共三级，升级花费5/10/15金币，收线加快、张力增长降低；空闲或收鱼结果期间可升级，搏鱼时不能临时升级。金币和等级保存在本机。

## 操作与设置

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

- 抛竿与提竿：点击独立按钮或湖面，空格也可操作；正在抛竿/等待时按钮显示当前阶段并禁用。
- 收线：鼠标/手指按住收线按钮或湖面，松开即放线；触摸取消、失焦、暂停会释放输入，不会卡在持续收线。
- 键盘：搏鱼时按住空格收线，松开放线；焦点在按钮上也拦截空格默认点击，避免重复触发。收线按钮用Enter/读屏激活可切换持续收线，再次激活放线。
- 湖面包括抛竿抛物线、浮漂起伏/下沉、水波、鱼影游动、搏鱼跟线与钓获展示；动画和物理使用同一暂停时钟。系统“减少动态效果”偏好减少装饰运动与抛竿幅度，保留必要玩法反馈。

## 数据与资源

本机localStorage保存设置、湖泊解锁、金币/鱼竿等级和分难度/分湖纪录，失败回退当前页内存，不上传数据。不保存当前鱼饵、计时和未完成搏鱼。新版成绩以v2键隔离，保留旧成绩数据。script.js为独立规则与Canvas绘制；style.css只维护玩法仪表和输入状态；logo.svg为本地SVG物件图形；base.css、interface.js、icons.js由根公共源同步。

## 已知范围与限制

休闲搏鱼模拟，不模拟真实生态。鱼种与等待时间带随机性；张力曲线随鱼种、湖泊和难度变化。单局鱼获不跨局累计。Canvas主场景使用600×600逻辑坐标，手机提示与张力仪表为可读DOM；无外部图片、音乐、字体或运行依赖。
