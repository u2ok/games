# 翻灯谜题

直接打开index.html或静态托管，整个目录可独立复制，无外部运行依赖。

## 玩法与操作

点击一盏灯会切换自己及上下左右四邻的亮灭状态，把所有灯熄灭即通关。键盘方向选择、空格切换；提示用模2消元给出当前局面的一步解。

P暂停/继续，Enter开始/继续，Shift+Enter重开。触控和鼠标均按画布提示操作；方向/数字快捷键见界面。

## 设置与存储

三档难度下一局生效；音效默认关闭。记录按难度和关卡隔离，本机存储失败回退页内内存，损坏设置恢复默认。提示、撤销等辅助局不写独立纪录。页面失焦或更多菜单自动暂停，关闭后手动继续；动态效果遵循减少动态效果设置。

## 资源与范围

script.js为独立规则与绘制；style.css仅玩法输入；logo.svg本地物件图形；../../shared/base.css/../../shared/interface.js/../../shared/icons.js由页面直接引用根公共源。

12关，3/4/5阶；合法翻转生成，保证可解，模2高斯消元提示不宣称最少步。

## 验证

测试范围及证据见根TEST-REPORT.md，浏览器视口/输入模拟不等同物理手机或人工全部通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。
