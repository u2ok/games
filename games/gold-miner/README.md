# 黄金矿工

直接打开index.html或静态托管，整个目录可独立复制，无外部运行依赖。

## 玩法与操作

钩爪自动左右摆动，点击、空格或下方按钮放钩。金块与宝石计分，石块价值低且回收慢。每关60秒，在时限内达到目标即可过关；道具炸药可丢弃当前抓住的物件，每关两次。

P暂停/继续，Enter开始/继续，Shift+Enter重开。触控和鼠标均按画布提示操作；方向/数字快捷键见界面。

## 设置与存储

三档难度下一局生效；音效默认关闭。记录按难度和关卡隔离，本机存储失败回退页内内存，损坏设置恢复默认。提示、撤销等辅助局不写独立纪录。页面失焦或更多菜单自动暂停，关闭后手动继续；动态效果遵循减少动态效果设置。

## 资源与范围

script.js为独立规则与绘制；style.css仅玩法输入；logo.svg本地物件图形；../../shared/base.css/../../shared/interface.js/../../shared/icons.js由页面直接引用根公共源。

24关，60秒达标制；原有前8关及存储进度保留，新增16关采用固定种子的矿物位置与不同矿脉分布，目标分数分段缓慢提高，三档难度分别设置目标。手机关卡菜单分为20关与4关两页。物件重量决定回收速度，炸药仅在带物回收时可用。舞台采用矿工、绞盘、三爪抓钩、木撑矿井及分层土壤绘制；金矿、岩石和切面宝石保持各自抓取半径，价值牌与目标进度常驻显示。抓取光圈、回收滚筒、矿工动作、宝石闪光及得分飘字随游戏暂停冻结；减少动态效果时关闭装饰运动，保留实际钩爪移动与得分反馈。Logo为抓钩夹住金矿的本地SVG，与大厅卡片共用。

## 验证

测试范围及证据见根TEST-REPORT.md，浏览器视口/输入模拟不等同物理手机或人工全部通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。公共布局直接维护shared/base.css，玩法私有样式维护本目录style.css；验证范围见根TEST-REPORT.md。
