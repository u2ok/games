# 数字华容道

直接打开 `index.html` 即可运行；不需要构建、依赖、网络或 ES6 Modules。

## 玩法

默认 4×4，按行将数字从 1 排列到 15，空格留在右下角。点击空格旁边的数字，将其移入空格；也可把相邻数字朝空格方向滑动，或使用方向键/WASD。按键表示数字的移动方向，例如左键将空格右侧的数字向左移入空格。

只有上下左右相邻数字可移动，不允许跨行跳跃。每次有效移动计一步，首次有效移动开始计时。成功后显示步数和用时。暂停、打开设置、打开手机菜单或页面失焦时停止计时，手动继续后恢复。

## 设置与记录

- 棋盘支持 3×3、4×4、5×5，默认为 4×4，修改在重新开始后生效。
- 随机局面通过对完成状态执行合法移动生成，保证可解且不是完成状态，不承诺最短解长度或均匀随机。
- 音效默认关闭，使用 Web Audio 合成。
- 最少完成步数按棋盘尺寸分别记录；数据仅保存在本机，存储失败时回退到内存并提示。

## 独立资源

`base.css`、`interface.js` 为统一基础副本，`style.css` 为棋盘专属样式，`script.js` 为封闭作用域中的全部逻辑。复制整个文件夹可独立运行，返回大厅链接应按目标位置调整。

桌面采用左棋盘右面板；手机菜单收纳设置和规则，棋盘按可用高度缩放。建议用现代浏览器运行。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，局内操作保留在游戏区下方。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`base.css`、`interface.js` 为公共源的独立副本，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；复制目录独立运行不依赖这些文档链接。
