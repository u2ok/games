# 炸弹人

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 玩法

8关单人炸弹人。方向键/WASD或方向按钮移动，空格/放炸弹放置2.2秒后爆炸的炸弹。爆炸十字扩散，石墙阻断，木箱被毁后停止传播；炸弹可连锁引爆。火焰伤害敌我，受伤扣1命并回起点，短暂无敌。木箱随机掉火力、容量或速度提升；炸弹所在格离开后不能穿过。击退全部敌人、炸开右下出口并走入通关；敌人和超时会造成失败。下关重置本关资源。

## 操作与设置

棋盘下方按方向区和操作区分组：PC方向键单排；手机及横屏采用十字排列（上键居中，左/下/右同排），下方为暂停/继续、放炸弹、重新开始及更多。

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

## 数据与资源

本机localStorage保存设置、关卡解锁和分难度/分关纪录，失败回退当前页内存，不上传数据。script.js为独立规则；style.css只维护棋盘；logo.svg为本地SVG物件图形；../../shared/base.css、../../shared/interface.js、../../shared/icons.js由页面直接引用根公共源。

## 已知范围与限制

八关使用随机木箱与逐步增加的敌人；敌人采用有限追踪，不提供多人联网。强化在下一关重置。

## 验证范围

模拟DOM规则回归与浏览器视口模拟证据见根TEST-REPORT.md；不等同真机或全部对局通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。公共布局直接维护shared/base.css，玩法私有样式维护本目录style.css；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
