# 推箱子

直接打开 `index.html` 即可运行；无构建工具、ES6 Modules、外部依赖或网络资源。

## 玩法

移动角色，把所有箱子推到带边框的目标点上。只能推、不能拉，每次只能推一个箱子。走进墙壁、连续两个箱子或将箱子推向墙壁的操作无效，也不计步。

- 方向键 / WASD、手机方向按钮或在地图滑动：移动一格。
- Z 或“撤销一步”：恢复上一有效移动，包括箱子位置、步数和推箱次数。
- “重新开始”：重玩本关。
- 过关后点击“下一关”，或从关卡选择中进入已经解锁的关卡。

包含 20 个固定关卡：前 6 关学习基本移动与推箱，第 7–20 关增加回身、转角、绕柱、回廊和多箱调度。新增关卡从完成状态反向拉箱制作后保存为固定地图，并用独立求解器寻找解法，再在实际游戏函数中回放全部移动，以验证每关可解。

旧关卡编号与纪录不变；旧版第 6 关已有通关纪录时，自动解锁第 7 关。关卡列表为五列排列，手机端在游戏菜单中查看。

箱子推入非目标墙角时会提示，但不会自动结束；可撤销或重玩。未实现完整死锁检测，也不提供自动解题。

## 暂停、设置与记录

打开设置、手机菜单、切换页面或窗口失焦时暂停，回来后手动继续。暂停期间不能移动或撤销。开启“目标圆点”可增加目标提示，关闭后仍保留目标边框。

音效默认关闭。最少步数按关卡分别保存，当前关卡和解锁进度也保存在本机；撤销已完成的关卡不会删除曾经取得的纪录或解锁进度。保存失败时降级为当前页面内存并提示。

## 文件

- `index.html`：独立语义化页面。
- `base.css`、`interface.js`：统一设计与手机游戏台的独立副本。
- `style.css`：地图、人物、箱子和目标的本地 CSS 图形。
- `script.js`：关卡、移动、撤销、进度和音效逻辑，封闭作用域运行。

复制整个文件夹可独立运行，返回大厅链接按目标位置调整。历史浏览器抽查见合集测试报告；不代表当前版本所有状态或真实设备均已验收。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`base.css`、`interface.js` 为公共源的独立副本，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；复制目录独立运行不依赖这些文档链接。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
