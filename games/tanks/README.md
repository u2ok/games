# 坦克大战

直接打开 `index.html` 运行，无构建、ES6 Modules、外部依赖和网络资源。

## 玩法

新增 12 个逐关解锁的基地防守关卡，每关六波。第一关保持原版地图和每波 4–9 辆的配置；每三关增加每波敌军数量，第七关起同时最多四辆，敌方移动和开火节奏也逐渐加快。击破一辆 +100 分，六波完成后进入下一关。基地被击中或生命耗尽时，本关失败，可重玩。

关卡：基地初战、双翼防线、中央堡垒、交叉火线、钢铁回廊、南线告急、三路突袭、密林据点、环形工事、双塔要塞、纵深防御、最后堡垒。

桌面在右侧选择已解锁关卡，手机在游戏菜单选择。切换关卡、重玩或进入下一关会重置生命、分数、地形和全部道具，每关初始三条生命。解锁与当前关卡保存在本机；最高分按关卡和难度分别记录。原版最高分保留为第一关纪录，不用未通关的历史分数推断通关。

砖墙可被任意一方子弹击碎，钢墙不可破坏；双方坦克都不能穿过墙壁、基地或其他坦克。玩家子弹不会伤害基地，敌军之间不互相伤害。出生/复活短暂无敌，复活会清除附近敌弹；复活区域全部被占领时结束。

## 道具

击破敌军的第一次和每第三次必掉道具，其余击破有 30% 机会掉落，场上最多三个。坦克接触拾取，18 秒未拾取自动消失。

| 地图标记 | 效果 |
| --- | --- |
| 护 | 无敌护盾 8 秒，不保护基地 |
| 生 | 生命 +1，最多 5 条 |
| 速 | 速射 10 秒，开火间隔由 0.28 秒减至 0.1 秒 |
| 冻 | 冻结敌军移动、开火、敌弹和增援 6 秒 |
| 爆 | 击破当前全部敌军、清除敌弹，每辆仍得 100 分，不连锁掉落 |

重复拾取刷新时长，不叠加。暂停和菜单不会消耗效果与道具存留时间；新一局清除全部道具效果。棋盘下方显示当前效果及剩余秒数。

## 操作与设置

- 方向键 / WASD：按住移动。
- 空格 / J：按住开火。按钮聚焦时空格保留其原生操作。
- 鼠标按住地图：朝指向的四个主方向之一开火。
- 手机方向按钮与开火按钮支持两指同时按住；松开、取消触摸或暂停时停止输入。

轻松、标准、挑战影响敌军移动和开火节奏，新一局生效。音效默认关闭。打开设置、手机菜单、页面隐藏或失焦时自动暂停，手动继续。

## 独立资源与限制

`../../game-base.css` 与 `../../game-interface.js` 为统一界面独立副本，`style.css` 定义手机控制区，`script.js` 包含地形、坦克、子弹、AI、波次、保存和 Canvas 绘制。复制目录可独立运行，返回大厅地址按目录调整。存储失败时回退页面内存并提示。

本版本为单人基地防守，AI 使用目标朝向与避障决策，不包含双人和关卡编辑器。Canvas 提供文字状态，未实现完整非视觉操作。历史浏览器抽查见合集测试报告；不代表当前版本所有状态或真实设备均已验收。



## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`../../game-base.css`、`../../game-interface.js` 直接引用根目录公共源，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；仅复制本目录不能完整运行，需携带根公共文件并保留相对路径。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
