# 弹弓投射

直接打开index.html即可运行，也支持普通静态托管。复制本目录仍可独立游玩，无外部运行依赖。

## 规则与操作

从弹弓附近向后拖动，松开发射；键盘左右调整方向、上下调整力度，空格发射。每关四发，击碎全部木箱获胜；轻松/标准/挑战的波及半径分别为80/70/60逻辑像素。木箱受冲击后倾倒下落，炸裂会波及附近木箱；为轻量街机近似物理。24关。

## 设置、记录与生命周期

三档难度在重新开始后生效。P暂停/继续，Enter准备或终局时开始/再玩，Shift+Enter重开。打开设置、页面隐藏或失焦时暂停，关闭后需手动继续。触摸取消及窗口尺寸改变会取消未完成输入，暂停清除按键状态并冻结动画时钟。减少动态效果偏好关闭装饰粒子；必要的运动轨迹仍保留。

最高得分按难度及关卡独立保存。谜题通关分=max(10,1000-完整秒数×2-操作次数×5)；叠楼、接水果、套圈及节奏记忆等在界面结算中说明本局成绩。使用辅助不计最佳。localStorage损坏时恢复默认，写入失败在当前页面保留纪录。共24关，所有关卡自由选择；当前关和完成进度保存在本机。

## 资源与限制

script.js为独立规则及本地Canvas物件绘制；logo.svg用于标题和导航卡片。base.css/interface.js/icons.js从根公共源同步，私有CSS仅定义输入手势。画布与命中统一600×600逻辑坐标。单一requestAnimationFrame，无业务setTimeout或异步动画回调。

物理类为面向玩法的近似模拟，不宣称精确现实物理；离线单机，不依赖远程图片或音频。测试范围与浏览器模拟/真机区别见根TEST-REPORT.md。
