# 军棋

独立原生小游戏，打开本目录`index.html`即可运行，无联网依赖。

## 两种模式

- **布局对弈（暗棋对碰）**：你执红方先行。开始布局后点击两枚己方棋子交换，或随机布局。军旗必须在大本营，地雷只能在最后两排，炸弹不能放最前排，行营留空。完成布局后红方先行。自己始终可见己方军衔，对手棋子只显示背面，可以直接进攻敌方暗棋；系统充当裁判，只报告碰子胜负，不公开存活敌棋军衔。司令阵亡时按规则亮旗，终局可查看全盘。
- **翻棋对弈（混排变体）**：双方50枚棋子随机混排于非行营站点，全部盖住。你先翻，首次翻出的颜色成为你的阵营。每回合翻一子，或移动一枚己方明子。暗子不能被攻击，也阻挡路线。此变体的旗雷位置不受初始布阵限制，军旗可能出现在大本营之外，不等同于传统裁判暗棋。

每方25子：司令1、军长1、师长2、旅长2、团长2、营长2、连长3、排长3、工兵3、地雷3、炸弹2、军旗1。

棋盘按用户参考图重绘为木纹底、绿色兵站/圆形行营、黑白铁路和细公路。上方行营位于第3排第2/4列、第4排第3列、第5排第2/4列，下方按中心镜像；大本营位于双方底线第2/4列。中央三条前线通道和两处不可通行山界只是通道标识，不增加可落子站点。

## 行棋与胜负

公路沿线走一步；行营有斜向道路。铁路可沿直线通过任意空站，工兵还能沿铁路转弯。中央仅左右两翼及中间桥梁连接两方。沿途棋子阻挡，不能跳子。行营里的棋子不能被攻击；大本营内可移动棋子可以走出，两个模式均适用；军旗和地雷仍不能移动。

司令至工兵依次大小吃子，同级同归于尽。翻棋模式禁止小子主动攻击大子，其他普通子也不能主动碰雷；工兵仍可排雷。布局暗棋保留碰子裁判规则，进攻大子或地雷可能损失；炸弹与任何棋子同归于尽。夺取军旗立即获胜（炸弹同样可夺旗）；司令阵亡时公开本方军旗。没有暗子且一方无合法走法时该方负。同一局面且同一方行动第三次出现，或连续100步未吃子/翻子，判和。

手机提示区使用公共`data-stable-feedback`能力预留三行，避免思考、翻子、走棋、碰子及亮旗提示切换时改变棋盘尺寸；横竖屏或窗口尺寸变化仍正常重新适配。

棋盘站点坐标、公路/铁路图、路径提示和命中判定共享同一模型。显示最近一手的路径与起止位置；选子后用方向键查看合法落点时显示路径预览。山界与前线间隙不能选为落点。

点击/触摸选择棋子，再选标记落点；方向键移动光标，Enter/空格操作，Escape取消选择。P暂停/继续，Enter在准备/暂停/终局开始或继续，Shift+Enter重开。失焦、隐藏页面、打开设置或菜单暂停；回来后手动继续。

## 电脑与设置

翻棋模式使用最多1/3/4层迭代加深、alpha-beta和带边界类型的局面缓存，三档时间预算60/160/300毫秒、节点上限1000/4500/9000。翻子与走棋使用同一回合价值：翻子计入对手立即应手风险，开路、己方可动子数量、连续翻子和局部支援影响信息收益；相近价值优先选择有追击、救子、吃子或安全占位收益的走棋；没有这些收益时优先探索，避免用空走替代翻子。明确可救的受威胁子和军旗优先处理，不盲目翻子。深层搜索保留有限的抽象翻子回合，不假设新子身份，也不把尚有暗子的局面误判为无着。

布局暗棋模式按轻松/标准/挑战最多采样6/12/20轮，标准/挑战考虑对手应手，挑战还检查部分反吃；预算同为60/160/300毫秒。采样根据候选军衔和初始子力数量上限进行约束分配，避免重复军旗或超额司令；所有候选只累计完整的同一轮样本，未完成整轮丢弃。限时与候选裁剪意味着不保证最优或竞技棋力。

评分考虑子力、可行铁路、公路距离、行营、威胁、排雷、夺旗及保护军旗。翻棋混排不套用“红向上、蓝向下”的布局方向，而是沿实际可行的公路/铁路回合路径反向传播公开目标的折扣收益，权衡目标价值、所需回合、眼前被吃风险及安全行营占位；友军与暗子仍挡路，不把几何上接近但不可达的目标算作收益。双方分别保留最近8次行棋，翻棋同时记录走后公开局面，用于惩罚无收益回走、不同走法造成的重复局面和循环；真实救子或保护同伴的回撤会降低历史惩罚；翻子连续次数独立统计，重开清理。仍有可选翻子回合时，剔除既无追击/吃子/救子/保护同伴收益、也无安全占位收益的空走；没有暗子时保留必要的合法移动和原有和棋规则。近优走法保留小幅随机。

布局模式的AI输入保留自己的真实军衔，对手只保留阵营、公开亮旗及候选军衔；不会接收对手真实军衔。候选范围来自合法初始摆放、公开走法（包括工兵铁路转弯）及己方已知军衔参与的碰子结果。双方推断分别维护；未碰过的未知子不因真实身份不同而改变输入。采样是满足剩余数量上限的近似推断，不是完整的后验概率模型。翻棋模式移除所有盖住棋子的身份，翻子位置依据已公开局面决定。

难度在重新开始后生效。设置、模式与按模式/难度区分的胜负局数保存在本机（暗棋对碰使用独立`layout-dark`纪录键，旧明棋记录保留而不混入）；存储失败时退回当前页面内存。重新开始会取消旧的电脑回调。

## 文件及验证

`script.js`实现规则、输入和AI；`style.css`仅定义棋盘比例；`base.css/interface.js/icons.js`是公共源同步副本；`logo.svg`为本地旗帜与军棋物件图案。复制整个目录仍可运行，返回大厅路径按需调整。

自动规则回归、资源检查及浏览器视口验证范围见根`TEST-REPORT.md`，不将模拟DOM或桌面视口模拟视作真机验证。
