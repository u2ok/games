# 仓库停车场

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部依赖。

## 玩法与关卡

6×6停车场，横车只能左右移动，竖车只能上下移动；将红色GO车辆移到第三行右侧出口。车辆不能穿过或重叠，每跨一格计一步。一次长拖动按跨过的格数计步，撤销逐格回退。

三档各20道固定关卡，共60关。入门最短10–21步，进阶22–25步，挑战34–57步；各档按最短解非递减排列。关卡来自不同的车辆拓扑，部分挑战题使用同拓扑的不同深层局面。离线枚举完整连通分量，再从全部出口状态反向广搜，得到最短单格距离；运行时测试使用实际规则独立求解并回放每关。

提示通过位置向量广搜给出当前最短路线下一步，最多80000状态；使用提示不写独立最少步数纪录。通关显示实际步数及最短步数，相等时标记完美路线。每档逐关解锁，解锁进度沿用同一套20关索引。

## 操作与设置

鼠标/触屏可拖动车身；也可点选车辆后用方向键或下方方向按钮移动，点同轴空位移一格。P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。页面隐藏、失焦或打开更多自动暂停；手动恢复。难度下一局生效。

完整SVG车身包含车窗、车灯和轮胎；三格车采用独立轻卡造型，货厢与短驾驶室分离，前后轴对齐，两格车保留轿车比例；选中显示行驶轨道，移动平滑过渡，受阻短促反馈，通关驶出。遵循系统减少动态效果偏好；公共导航、按钮、信息卡保持统一样式。

## 数据与文件

本机localStorage保存设置、解锁和分难度/分关纪录，失败回退内存。新版使用mini-games:parking:v2命名空间，旧随机关卡数据保留但不混入固定题纪录。script.js含题库、规则、交互；style.css仅停车场及玩法表现；logo.svg为本地SVG；base.css、interface.js、icons.js由根公共源同步。

## 验证范围

60关最短解与完整移动回放属于模拟DOM验证；Chrome五种视口检查布局、拖动及暂停，另有触屏输入模拟。不是物理手机或人工逐关通关，证据见根TEST-REPORT.md。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
