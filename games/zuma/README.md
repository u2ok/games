# 祖玛

直接打开index.html或静态托管，整个目录可独立复制，无外部运行依赖。

## 玩法与操作

移动指针瞄准，点击或空格发射；交换按钮或X切换备用颜色。球链沿S形轨道推进，同色至少三颗相连消除，缺口闭合可连锁。共发出30颗轨道球，清空获胜；球进入终点即失败。

P暂停/继续，Enter开始/继续，Shift+Enter重开。触控和鼠标均按画布提示操作；方向/数字快捷键见界面。

## 设置与存储

三档难度下一局生效；音效默认关闭。记录按难度和关卡隔离，本机存储失败回退页内内存，损坏设置恢复默认。提示、撤销等辅助局不写独立纪录。页面失焦或更多菜单自动暂停，关闭后手动继续；动态效果遵循减少动态效果设置。

## 资源与范围

script.js为独立规则与绘制；style.css仅玩法输入；logo.svg本地物件图形；base.css/interface.js/icons.js由根公共源同步。

原创S形轨道彩球游戏，非商业作品复刻。三档推进速度，30球一局，数字辅助辨色。场景采用石槽轨道、植物点缀及石雕发射台，轨道按实际弧长采样，让弯道球距均匀。发射带拖尾、炮筒后坐力和炮口闪光；消除带彩色粒子、光圈及分数/连锁提示，缺口补位采用仅绘制插值，规则结算即时完成。临近终点显示警示圈。暂停冻结动画且指针不再改变炮台方向；重开清理特效。减少动态效果时关闭拖尾、后坐力、闪动及消除装饰，保留实际运动、规则和文字提示。
