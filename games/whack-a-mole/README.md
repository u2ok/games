# 打地鼠

直接打开 `index.html`，或从导航大厅进入。原生HTML/CSS/普通JavaScript，无构建、网络或模块依赖，可复制目录独立运行。

## 规则与操作

一局60秒，九个洞口随机出现地鼠。点击或触摸命中，每次10分；第6次连续命中起增加5分，第11次再增加5分，最高每次30分。漏击或打空清零连击，不扣已有分数。同一只地鼠只能命中一次。

数字键1–9依次对应从左到右、从上到下的洞口（不是小键盘空间布局）。P暂停/继续，Enter开始/继续/再玩，Shift+Enter重开。输入框及弹层内不触发通用快捷键。

轻松/标准/挑战分别控制地鼠停留与出现间隔，难度在新一局生效。每档最佳成绩独立保存在localStorage；失败回退内存。音效默认关闭。失焦、隐藏页面或打开菜单时暂停，暂停冻结剩余时间与目标停留时间。

## 文件与限制

`base.css`、`interface.js`为公共副本；`style.css`仅绘制洞口；`script.js`管理规则、计时、输入、存储；`logo.svg`为本地标签及标题图标。返回大厅链接按复制位置调整。

不含炸弹和多人模式。需快速视觉定位，暂未提供等价的非视觉玩法。浏览器模拟检查不替代真实手机触屏与音效验证。
