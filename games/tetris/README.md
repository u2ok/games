# 俄罗斯方块

打开本目录 `index.html` 即可运行，无构建工具、ES6 Modules、外部字体或音频依赖。

## 操作与规则

- ←/→ 或 A/D：左右移动；↓/S：软降。
- ↑/W/X：顺时针旋转；Z：逆时针旋转。
- 空格：游戏进行中直接落下并锁定当前方块，即使焦点留在开始、重开或触控按钮上也生效，同时阻止按钮被空格重复点击；按住只硬降一次。准备、暂停、终局、编辑区及弹窗中不触发硬降。
- 手机使用底部六个按钮：旋转、逆转、直接落下、左移、下移、右移。

棋盘为 10×20，使用 I/J/L/O/S/T/Z 七种方块。每袋包含全部七种，洗牌后逐个发出；显示下一块，下落提示默认关闭，可在设置中开启并保存，立即生效。每消 10 行提升一级并加速，堆到顶部结束。

单次消除 1/2/3/4 行分别获得 100/300/500/800 × 当前等级分；软降每格 +1，硬降每格 +2。旋转使用简化踢墙，依次尝试原位、左右一/两格、上移一/两格，不是完整 SRS。不支持暂存、T-spin、连击奖励或锁定延迟。

## 设置与记录

速度支持慢速（初始 900ms/格）、标准（700ms/格）、快速（450ms/格），每级乘 0.82，最快 80ms/格。设置在下一局生效，三档速度分别保存最高分。音效默认关闭。

打开设置、手机菜单、离开页面或失焦时暂停，手动继续。最佳成绩和设置保存在本机，存储不可用时回退内存并提示。

## 独立资源

`base.css`、`interface.js` 是统一布局的独立副本；`style.css` 只定义本游戏触屏控件；`script.js` 包含棋盘、随机、旋转、碰撞、消行、计分和绘制。正方形舞台中间显示长方形棋盘，两侧显示等级、消行和下一块。Canvas 提供文字状态，但不提供完整非视觉操作。

复制整个目录可独立运行，返回大厅地址需要按目录调整。历史浏览器抽查见合集测试报告；不代表当前版本所有状态或真实设备均已验收。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`base.css`、`interface.js` 为公共源的独立副本，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；复制目录独立运行不依赖这些文档链接。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
