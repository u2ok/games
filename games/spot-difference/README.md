# 找茬

直接打开index.html，或复制本目录到静态服务器；无外部依赖。

## 玩法

六主题（林间、海岸、花园、街角、雪乡、星夜）各六关，共36关。完整连续场景插画，包含远山/海面/天空、地面、建筑主体和前景细节；固定种子生成各关构图，不采用物件网格或小图拼贴；每关5–7处物件缺失、变色或形态差异。点击任一画面，找到后两幅同时标记编号。没有倒计时，错点只统计次数；已找到位置不重复计错。全部找到即通关。

放大细看依次切换原画、找茬图、双图。提示显示一处金色虚线3秒，仍需点击，使用提示的局不记最快。所有关卡自由选择，保存当前关和完成进度；关卡按钮仅显示数字，列表下方显示完成总数，按钮辅助标签保留已完成状态。最快纪录按关隔离，向上取整至秒；不对误点额外罚时。

## 操作与设置

鼠标/触摸点击；画布聚焦后方向键移动游标，Shift精调，Enter确认。P暂停/继续，Enter准备时开始，Shift+Enter重开。菜单、失焦、页面隐藏暂停，手动继续；触摸取消或移动超过12CSS像素不确认。音效可关闭。单个requestAnimationFrame驱动计时、光圈和通关粒子，暂停冻结，减少动态效果关闭扩散和粒子。

## 文件与限制

script.js包含规则、固定场景数据生成和Canvas矢量绘制；logo.svg为本地物件式放大镜与风景卡。style.css只定义画布比例和输入，公共base.css/interface.js/icons.js由根同步。localStorage损坏时校验回退，写入失败仅在当前页面保留状态。

画面为原创简约矢量插画，36关不使用远程图片。为照顾小屏，点击允许适度容差；可放大查看。验证范围见根TEST-REPORT.md，浏览器视口模拟不等同真机。
