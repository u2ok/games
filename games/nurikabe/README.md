# 数墙

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 玩法

5×5数墙：白岛中恰好一个数字，面积等于数字；不同白岛不能上下左右接触。所有黑格连成一个区域，不能出现2×2全黑。必须确定所有格子。点击在当前颜色与未知间切换，模式按钮切换标白/涂黑，右键涂黑。方向键选格、Enter标记。三档各6道独立验证唯一解基础题，12关旋转镜像变化；通关只验证规则，不要求与预设答案一致。检查验证当前标记是否存在合法延伸；提示只填写所有可行解一致的格子，不改写已有标记。检查与提示计辅助局，不记最少步数。

## 操作与设置

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

## 数据与资源

本机localStorage保存设置、关卡解锁和分难度/分关纪录，失败回退当前页内存，不上传数据。script.js为独立规则；style.css只维护棋盘；logo.svg为本地SVG物件图形；../../game-base.css、../../game-interface.js、../../game-icons.js由页面直接引用根公共源。

## 已知范围与限制

当前棋盘固定5×5，三档各6道经唯一解验证的基础题，经旋转与镜像组成12关，不是更大尺寸题库。提示和检查局不写独立解题纪录。

## 验证范围

模拟DOM规则回归与浏览器视口模拟证据见根TEST-REPORT.md；不等同真机或全部对局通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
