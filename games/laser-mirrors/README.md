# 激光折射

直接打开index.html即可运行，也支持普通静态托管。复制本目录仍可独立游玩，无外部运行依赖。

## 规则与操作

24关，轻松/标准/挑战为5/6/7阶。光束必须按编号经过1/2/3个能量点后照到右侧接收器；只照亮接收器不算成功。每关有1/2/3面带铆钉的固定镜，其余镜面点击或回车旋转。路线包含回折，并混入非必经镜面；光遇墙停止。旋转上限为预设可行方案所需次数加4/2/0次，不宣称该方案最优；用完次数仍未接通即失败。先观察固定镜、能量点和光路再操作，方向键选格。提示标出预设可行方案的一块偏差镜，不补充次数，辅助局不计最佳。

## 设置、记录与生命周期

三档难度在重新开始后生效。P暂停/继续，Enter准备或终局时开始/再玩，Shift+Enter重开。打开设置、页面隐藏或失焦时暂停，关闭后需手动继续。触摸取消及窗口尺寸改变会取消未完成输入，暂停清除按键状态并冻结动画时钟。减少动态效果偏好关闭装饰粒子；必要的运动轨迹仍保留。

v2限次规则的最佳得分和完成进度独立保存，旧数据保留但不计入新规则。最高得分按难度及关卡独立保存。谜题通关分=max(10,1000-完整秒数×2-操作次数×5)；叠楼、接水果、套圈及节奏记忆等在界面结算中说明本局成绩。使用辅助不计最佳。localStorage损坏时恢复默认，写入失败在当前页面保留纪录。共24关，所有关卡自由选择；当前关和完成进度保存在本机。

## 资源与限制

script.js为独立规则及本地Canvas物件绘制；logo.svg用于标题和导航卡片。../../shared/base.css/../../shared/interface.js/../../shared/icons.js从根公共源同步，私有CSS仅定义输入手势。画布与命中统一600×600逻辑坐标。单一requestAnimationFrame，无业务setTimeout或异步动画回调。

物理类为面向玩法的近似模拟，不宣称精确现实物理；离线单机，不依赖远程图片或音频。测试范围与浏览器模拟/真机区别见根TEST-REPORT.md。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。公共布局直接维护shared/base.css，玩法私有样式维护本目录style.css；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
