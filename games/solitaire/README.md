# 接龙纸牌（Klondike）

原生 HTML/CSS/JavaScript，直接打开 `index.html` 或静态托管即可，无构建工具、ES6 Modules 或远程资源。

## 规则

使用标准 52 张牌，无大小王。七列分别发 1–7 张，只有列顶朝上，其余 24 张为牌库。

- 列间按红黑交替、点数递减排列，可移动一张或整段连续合法牌串。
- 空列只能放 K 或以 K 开头的合法牌串；移走列顶后，下一张背面牌自动翻开。
- 四个收牌区分别对应 ♠♥♣♦，从 A 开始同花递增，直到 K。
- 单张翻牌为默认，也支持每次翻三张；废牌只可使用顶牌。牌库为空时可以无限次回收，顺序保持不变。
- 收齐 52 张获胜；随机发牌不保证每局可解。

## 操作

先点击一张朝上的牌，再点目标列或收牌区。再次点击同一来源取消。双击/双点一张列顶牌或废牌可收牌，也可选择后点击“收牌”；桌面支持拖动整段牌串到目标列。

“提示”寻找可行移牌并标记来源与目标，优先收牌；没有找到时建议翻牌或撤销，不进行完备的局面求解。“撤销”最多回退 200 步，包括翻牌、回收、翻开暗牌和胜利最后一步；用时和历史最佳纪录不回退。

每次翻牌、回收、合法移牌各计一步，首次有效操作开始计时。打开设置、菜单或页面失焦时暂停。最快完成秒数按翻一张/三张分别保存，允许使用提示和撤销。

## 独立资源与手机适配

`../../shared/base.css` 和 `../../shared/interface.js` 为随游戏保存的统一基础；`style.css` 绘制牌桌与牌面，`script.js` 管理全部状态。纸牌叠放间距随列高动态压缩，避免长列溢出。手机直接点选，棋盘与撤销、提示、收牌按钮同屏显示。复制目录即可独立运行，返回大厅链接应按位置调整。

音效默认关闭。设置和纪录保存在本机，存储受限时退回内存；当前牌局不跨刷新恢复。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`../../shared/base.css`、`../../shared/interface.js` 直接引用根目录公共源，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；仅复制本目录不能完整运行，需携带shared公共文件并保留相对路径。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。

牌面花色及空收牌区的SVG由本游戏script.js的suitSVG维护，不依赖公共图标注册表或字符替换；公共icons.js只负责通用界面。
