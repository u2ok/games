# 斗兽棋

直接打开 index.html，或用静态服务器托管；目录复制后可独立运行，无外部依赖。

## 规则

7列9行，红方先行。每方8兽：象8、狮7、虎6、豹5、狼4、狗3、猫2、鼠1。横竖走一格，大吃小，同阶互吃。陆地鼠可以吃象，象不能吃鼠。只有鼠可以进入河流；任何棋子都不能跨水陆边界吃子。两鼠同在水中可以互吃。

狮虎可以横竖跳过连续河流，途中任一方鼠都会阻挡，落点仍需满足吃子规则。己方不能进入己方兽穴，进入敌方兽穴立即获胜。进入敌方陷阱后兽阶为0，任何敌兽都可吃它（包括象吃陷阱内鼠）；离开后恢复兽阶。己方陷阱不削弱己方棋子。所有棋子被吃或无合法走法判负。

采用狼4狗3版本；不同实体棋规则可能采用狗4狼3等变体。水陆吃子、跳河规则参考 [Yellow Mountain Imports玩法说明](https://www.ymimports.com/pages/how-to-play-jungle)。本项目另外规定：含行棋方的相同局面出现三次，或连续100手未吃子，判和。

## 操作和设置

点击/触屏选择己方棋子，再点击标记的目的格。方向键移动光标，Enter或空格选子/走棋，Escape取消。P暂停/继续，Enter开始/继续，Shift+Enter重新开始。失焦、隐藏页面和打开设置时暂停，手动继续。

人机对战执红先行；双人交替操作。人机悔棋撤回最近一轮，双人撤回一手，终局不能悔棋。三档电脑：轻松随机合法走法，标准两层、挑战三层搜索，分别限制4000/12000节点；有限搜索不保证最佳走法。难度下一局生效。

## 数据与文件

本机 localStorage 保存音效、难度、模式和分模式胜局；存储失败降级为本页内存，不上传数据。script.js为独立规则与AI，style.css仅棋盘专用样式，logo.svg为本地狮子物件图形；base.css、interface.js、icons.js由根公共源同步。

## 验证边界

规则回归采用模拟DOM执行实际脚本；响应式检查采用浏览器视口模拟，非真机认证，也不代表穷举完整对局。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
