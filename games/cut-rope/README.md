# 割绳子

直接打开index.html或静态托管，整个目录可独立复制，无外部运行依赖。

## 玩法与操作

糖果悬在绳端摆动。点击绳索或按剪绳按钮，在合适的时机剪断，利用惯性落进下方收集杯。可先收集星星增加得分；撞到障碍会反弹，掉出底部失败。本关重试可直接恢复初始状态。

P暂停/继续，Enter开始/继续，Shift+Enter重开。触控和鼠标均按画布提示操作；方向/数字快捷键见界面。

## 设置与存储

三档难度下一局生效；音效默认关闭。记录按难度和关卡隔离，本机存储失败回退页内内存，损坏设置恢复默认。提示、撤销等辅助局不写独立纪录。页面失焦或更多菜单自动暂停，关闭后手动继续；动态效果遵循减少动态效果设置。

## 资源与范围

script.js为独立规则与绘制；style.css仅玩法输入；logo.svg本地物件图形；../../game-base.css/../../game-interface.js/../../game-icons.js由页面直接引用根公共源。

原创9关单绳摆锤物理谜题，三档收集杯宽度；不使用商业角色资源。关卡只要求入杯，三星属可选挑战。画布采用纸面背景、条纹包装糖果、纤维绳和带星章的收集杯；剪断显示两截绳回弹，下落带短拖尾，收星显示光圈与加分，入杯有缩入反馈。暂停冻结动画，重试清理特效；减少动态效果关闭回弹、旋转、拖尾及光圈，保留实际物理运动和文字/计分反馈。Logo为剪刀、断绳与糖果的本地SVG，大厅和标题共用。

## 验证

测试范围及证据见根TEST-REPORT.md，浏览器视口/输入模拟不等同物理手机或人工全部通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
