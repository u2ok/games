# 贪吃蛇

直接打开本目录 `index.html` 即可游戏，无需构建、依赖或网络连接。

## 规则与操作

- 棋盘为 20 × 20，初始长度 3 格。每吃一个食物增长一格、得 10 分；食物只出现在空格。
- 方向键或 WASD 控制，手机可使用方向按钮或在棋盘滑动。禁止直接反向，快速输入最多缓存两次转向。
- 空格暂停/继续，或点击暂停按钮。重新开始会立即创建新一局。
- 撞身体结束；默认撞墙结束，也可在设置中启用穿墙。填满棋盘即获胜。
- 非增长时允许移动到正在离开的尾格。
- 打开设置、切换标签、窗口失焦时自动暂停；回来后需手动继续。

## 画面

棋盘采用浅绿渐变与轻量格纹，蛇节保留逐格间隙，深绿蛇头的双眼和嘴线随方向旋转；橙色果实与石质障碍使用轻微厚度和高光。关闭网格辅助线时同时隐藏格纹与辅助线。视觉装饰不改变移动格数、碰撞或食物位置。

## 设置

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 音效 | 关闭 | 开启后通过 Web Audio 合成吃食物和结束音效 |
| 速度 | 标准 | 慢速 220ms、标准 145ms、快速 90ms，每个间隔移动一格 |
| 边界 | 撞墙结束 | 可切换穿墙模式 |
| 网格辅助线 | 显示 | 可隐藏 |

速度与边界设置在下一局生效，继续当前暂停局仍保持原规则。音效、网格立即生效。最佳成绩按三档速度、两种边界共六组记录；页面显示当前局规则对应的纪录。

## 文件与保存

- `index.html`：语义化页面、操作区域与设置对话框。
- `style.css`：棋盘与玩法专属样式，公共布局由 `../../shared/base.css`、`../../shared/interface.js` 提供。
- `script.js`：闭包中的游戏状态机、Canvas 绘制、输入、音效和持久化。

设置和成绩保存在浏览器 `localStorage`，键名前缀为 `mini-games:snake:`。存储不可用会提示并退回当前页面内存；刷新后可能丢失。音频不可用时静默运行。复制本文件夹可独立运行，但返回导航链接需视目标目录调整。

## 限制与验证建议

面向支持 Canvas、dialog、Pointer Events 的现代浏览器。首版不支持完整的屏幕阅读器游戏操作。若页面通过本地文件打开，浏览器可能隔离不同文件的存储；稳定的导航历史建议通过静态服务器使用。

验收时分别检查：撞墙/穿墙、自撞、吃食物、禁止反向、连续转向、暂停恢复、反复重开、设置延迟生效、六组纪录分离、禁用存储、键盘与触屏，以及棋盘尺寸。

## 闯关模式

右侧面板顶部切换经典/闯关。切换会结束当前局，选关后点击棋盘中的开始按钮。

| 关卡 | 食物目标 | 速度 | 障碍 |
| --- | --- | --- | --- |
| 1 轻松入门 | 3 | 慢速 | 无 |
| 2 节奏加速 | 5 | 标准 | 无 |
| 3 中央障碍 | 6 | 标准 | 中央带缺口十字 |
| 4 双通道 | 7 | 标准 | 双竖墙，各留两格通道 |
| 5 综合挑战 | 8 | 快速 | 双通道与底部横墙 |

闯关固定撞墙结束，撞石块也结束；食物不会出现在石块或蛇身上。每关通过后解锁下一关，可重试或重玩已解锁关卡；末关通过后可返回第一关。没有倒计时和生命次数。

解锁进度保存于 `mini-games:snake:completed`，与经典最佳成绩分开。速度和边界设置在闯关时禁用，回到经典模式恢复原设置；音效和网格仍可调整。

## 统一界面

`../../shared/base.css` 为项目共享的统一设计基础，`style.css` 仅包含专属棋盘样式。桌面左棋盘右面板；850px 以下切为竖向，设置使用底部面板。页面、操作、状态和说明使用一致的设计令牌。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`../../shared/base.css`、`../../shared/interface.js` 直接引用根目录公共源，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；仅复制本目录不能完整运行，需携带shared公共文件并保留相对路径。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。公共布局直接维护shared/base.css，玩法私有样式维护本目录style.css；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
