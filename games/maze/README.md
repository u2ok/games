# 迷宫探险

直接打开本目录index.html即可运行，或使用静态服务器托管，无构建、框架及运行时网络依赖。

## 规则与操作

蓝色圆点是玩家，金色菱形为宝石，旗帜是出口。收集全部3颗宝石后到达出口获胜；未集齐时到出口不会结束。墙不可穿越，走过的位置显示足迹。每次移动一格，碰墙不计步。

方向键/WASD、手机方向按钮或在地图上滑动均可移动。Canvas可聚焦后使用键盘，但不是完整非视觉迷宫实现。P暂停/继续；Enter开始/继续/再玩；Shift+Enter重新开始。重新开始会生成新迷宫，不保留上一张地图。

路线提示展示通往最近未收集宝石的最短路径，收齐后指向出口；一次移动后提示线消失。使用提示的本局不计最快纪录。

## 设置与纪录

迷宫尺寸：轻松11×11、标准15×15、挑战21×21，修改后重开生效。每张随机地图均连通，宝石不与起点或出口重叠。不同尺寸分别保存最快秒数，随机地图难度会有差别，纪录用于休闲挑战。计时从首次有效移动开始，暂停/失焦/打开设置时不计时。

音效默认关闭。设置、最快纪录使用本机存储；存储不可用退回内存并提示，不阻止游戏。页面失焦、隐藏或打开设置自动暂停，返回后手动继续。

## 文件与适配

index.html为入口，script.js为独立闭包玩法，style.css仅维护棋盘与必要输入，logo.svg为本地地图物件标识。base.css、interface.js、icons.js由公共源同步，单独复制目录仍可离线运行。返回大厅链接可按复制位置调整。

PC复用中央棋盘、右信息面板和下方操作栏；手机顶部完整信息、棋盘、操作栏和方向区；横屏左右布局。画布为600×600逻辑单位，CSS等比例展示。
