# 弹珠台

直接打开 index.html，或由静态服务器托管。目录可独立复制，无外部运行依赖。

## 玩法与操作

球初始停在右侧独立发球槽的弹簧承托上。点击发球或按空格后，球先沿槽竖直上行，从上端开口向左进入主场；在槽内不参与目标或挡板碰撞。掉球与复位后回到同一待发位置。按住左右按钮、左右方向键或A/D控制挡板；松开落下。撞击弹簧柱与目标得分，球落出底部失去一球，共三球。按住、释放和触摸取消均会更新挡板。

P 暂停/继续，Enter 开始/继续/下一关，Shift+Enter 重开。更多、失焦或隐藏页面自动暂停，关闭后手动继续。触屏取消会结束当前手势。

## 设置与存储

三档难度，下一局生效。localStorage 在本机保存设置、关卡进度与分难度/关卡纪录；失败回退页内内存。提示局不写独立解题纪录。

## 关卡、提示与实现范围

无关卡的三球高分挑战，三档重力370/440/510逻辑单位每秒平方。连续命中弹簧柱1.6秒内累积连击，最多四倍分；复位消耗一球。六次子步连续碰撞、动态挡板、轨迹、弹簧柱光环及粒子；减少动态效果时去掉装饰轨迹与粒子，物理运动保留。简化平面弹珠台，不包含真实机械倾斜与复杂升降轨道。

## 文件与验证

script.js 为独立规则，style.css 仅维护玩法舞台，logo.svg 为本地物件式图形；../../shared/base.css、../../shared/interface.js、../../shared/icons.js 由页面直接引用根公共源。验证范围见根 TEST-REPORT.md，不等同真机和所有随机局通关。

画布按实际显示尺寸与设备像素比重设背板，逻辑坐标与命中始终为600×600；减少动态效果不关闭必要的物理运动。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
