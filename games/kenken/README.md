# 肯肯算术棋

直接打开index.html或静态托管，整个目录可独立复制，无外部运行依赖。

## 玩法与操作

每行每列填入1至N且不重复；粗线分区左上角是目标数与运算符。加法、乘法用于整个分区，减法和除法只用于两格且不区分顺序；单格直接等于目标。点击格后用数字键或下方数字按钮输入，擦除可清空。检查只报告当前明确冲突，不泄露答案。

P暂停/继续，Enter开始/继续，Shift+Enter重开。触控和鼠标均按画布提示操作；方向/数字快捷键见界面。

## 设置与存储

三档难度下一局生效；音效默认关闭。记录按难度和关卡隔离，本机存储失败回退页内内存，损坏设置恢复默认。提示、撤销等辅助局不写独立纪录。页面失焦或更多菜单自动暂停，关闭后手动继续；动态效果遵循减少动态效果设置。

## 资源与范围

script.js为独立规则与绘制；style.css仅玩法输入；logo.svg本地物件图形；../../shared/base.css/../../shared/interface.js/../../shared/icons.js由页面直接引用根公共源。

三档分别有30关，共90道固定题目，对应3/4/5阶；原有前12关保持不变，新关卡接续解锁。同一难度和关卡固定对应同一道题，重开、返回或刷新不会换题；当前关与解锁进度在本机保存，关卡按钮同步标出当前关。拉丁方与单/双格算术分区保证至少一个解，不承诺唯一解；通关按规则接纳所有合法解。固定题目的最快记录使用v2记录键，旧随机题成绩保留但不混用，原设置和解锁进度继续沿用。

数字键独立成行，只显示当前阶数可用的数字。PC辅助动作空间足够时同排，手机按擦除/检查/撤销与暂停/重开/更多分组排列，窄屏自然换行。选中格对应的数字键显示选中状态；空格不可擦除，没有历史时不可撤销，重复输入同一个数字不增加撤销记录。

## 验证

测试范围及证据见根TEST-REPORT.md，浏览器视口/输入模拟不等同物理手机或人工全部通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
