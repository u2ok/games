# 三消游戏

直接打开本目录index.html或静态托管运行，无构建、框架、ES6 Modules或外部网络依赖。

## 规则与目标

8×8棋盘，交换相邻图案，使横向或纵向连续3个及以上相同图案消除。无效交换原样退回，不扣步；每次有效交换只扣一步。交叉匹配位置只计一次。图案自动下落并补充新图案，触发连锁；每块基础10分，连锁第N轮按N倍计分。限定步数内达到目标获胜，最后一步仍会结算全部连锁后判断胜负。

轻松：4种图案、35步、1200分；标准：5种图案、28步、2200分；挑战：6种图案、26步、1900分；大师：7种图案、24步、1500分。图案越多，消除与连锁机会越少，因此高档目标分按得分机会下调，难度不由目标分单独决定。优先寻找四连、五连及交叉消除，规划下落后的连锁，才能提高得分效率。初始棋盘无现成连线且保证存在有效交换。无可走时自动重排，不扣步；手动洗牌扣一步，最后一步洗牌也会结算。重排优先保留各图案数量，多次失败则重建稳定可玩棋盘。连锁最多结算30轮，异常随机源导致仍有连线时重建棋盘，避免无限循环。

提示用虚线标记一对可交换图案，不扣步，使用后不计最佳纪录。最佳得分按难度和规则版本隔离，终局保存；新版不混用旧版纪录，旧存储不删除；难度在重新开始后生效。图案同时用不同形状与颜色区分。

## 操作和公共功能

点击一块再点击相邻块，或向相邻方向滑动。重复点击可取消；点击非相邻格改选。键盘Tab进入棋盘，方向键移动焦点，Enter/空格选择并交换，Escape取消选中。

P暂停/继续；Enter准备、暂停和终局时开始/继续/再玩；Shift+Enter重新开始。开始、重开会生成新棋盘。打开设置、失焦或隐藏自动暂停，暂停冻结消除与下落阶段，返回后手动继续。

音效默认关闭。设置与纪录保存在本机，存储不可用回退内存并提示。手机/横屏使用公共布局，操作不藏入菜单。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
