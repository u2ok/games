# 吃豆迷宫

直接打开index.html或静态托管，整个目录可独立复制，无外部运行依赖。

## 玩法与操作

方向键/WASD或方向按钮移动，吃完所有豆子获胜。大能量豆提供六秒反击时间，碰到敌人可将其送回出生点；普通状态碰敌损失生命，三条生命耗尽结束。敌人会追踪路线，普通豆10分，能量豆50分，反击200分。

P暂停/继续，Enter开始/继续，Shift+Enter重开。触控和鼠标均按画布提示操作；方向/数字快捷键见界面。

## 设置与存储

三档难度下一局生效；音效默认关闭。记录按难度和关卡隔离，本机存储失败回退页内内存，损坏设置恢复默认。提示、撤销等辅助局不写独立纪录。页面失焦或更多菜单自动暂停，关闭后手动继续；动态效果遵循减少动态效果设置。

## 资源与范围

script.js为独立规则与绘制；style.css仅玩法输入；logo.svg本地物件图形；base.css/interface.js/icons.js由根公共源同步。

原创固定15×15迷宫，两或三名追兵采用格点距离寻路；暂停停止移动与能量计时，不含商业角色和音频。

## 验证

测试范围及证据见根TEST-REPORT.md，浏览器视口/输入模拟不等同物理手机或人工全部通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
