# 数回

直接打开 index.html，或由静态服务器托管。目录可独立复制，无外部运行依赖。

## 玩法与操作

点击网格边循环画线、排除、清空，也可按住拖画连续边。数字表示该格四边中的线段数。最终必须形成一条不分叉、不交叉的闭合回路，不能有多个小圈。

P 暂停/继续，Enter 开始/继续/下一关，Shift+Enter 重开。更多、失焦或隐藏页面自动暂停，关闭后手动继续。触屏取消会结束当前手势。

## 设置与存储

三档难度，下一局生效。localStorage 在本机保存设置、关卡进度与分难度/关卡纪录；失败回退页内内存。提示局不写独立解题纪录。

## 关卡、提示与实现范围

12关，三档4×4/5×5/6×6，难度同时调整数字揭示比例。题面由单一合法边界构造，不宣称唯一解；检查数字、点度数和整条回路连通性。提示搜索预算5万节点，预算用尽明确告知，不据此判无解。

## 文件与验证

script.js 为独立规则，style.css 仅维护玩法舞台，logo.svg 为本地物件式图形；../../game-base.css、../../game-interface.js、../../game-icons.js 由页面直接引用根公共源。验证范围见根 TEST-REPORT.md，不等同真机和所有随机局通关。

规则参考：[Nikoli官方说明](https://www.nikoli.co.jp/en/puzzles/slitherlink/)。题面、代码和SVG均为本项目实现，运行不请求外站。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
