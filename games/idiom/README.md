# 成语挑战

读懂一词，点亮一页。直接打开index.html，或复制本目录独立运行。32条常用成语、本地题库，无需联网或构建。

## 题型与规则

- **释义寻词**：根据常用义简述，从四个成语中选择答案。
- **一字补全**：观察四字字笺，为缺失位置选一个字。提交后补全字笺并显示释义。
- **情境辨义**：阅读原创练习句，为空缺选择合适的成语。
- **混合挑战**：三种题型轮流穿插，起始次序随机。每局5/10/15题，同一成语不重复；题目与选项洗牌，优先抽近期未见的成语，近期记录最多32条。不承诺多局完全无重复。

答对基础10分，连续无提示答对依次得10、11、12、13、14分，之后封顶14分。答错或跳过得0分，并重置连击。每局有两次提示，每题最多使用一次，排除两个错误选项；提示题答对得5分，答错仍为0分，均重置连击。提示后的排除状态在暂停恢复时保留。

答案提交后锁定，显示正确项与释义或例句；需要主动进入下一题，不自动跳走。整局结束后可选择任意题目回顾，回顾不再次计分。最佳分按题型和题量分别保存；五题无提示全对最高60分，十题130分，十五题200分。

## 操作与界面

点击或轻触答案，也可用数字1–4；Enter答后进入下一题，原生按钮保留Tab/Enter操作。P暂停/继续，Shift+Enter重开。输入框、下拉框、输入法、组合键与长按不误提交。

打开更多、页面隐藏或失焦自动暂停，回来手动继续；暂停时答题区inert，不能用鼠标或键盘作答。设置在新局生效，重开清除本局提示、排除项、连击和答案。

游戏区使用纸页、四字字笺与本地书册铅笔SVG，题面短距离淡入、选字揭晓、答对轻弹。暂停冻结CSS动画；系统偏好减少动态效果时取消动画。不设倒计时，不因动画延迟提交或自动切题；沿用公共导航、信息面板、操作栏和原生设置控件。

## 词库与查阅

word-bank.js包含稳定ID、四字成语、常用义简述、带占位符的原创例句、三项人工挑选的干扰成语、缺字位置和汉典查阅地址。32条成语可生成三种题型，共96种题面组合，不是96条不同成语。

释义和例句按常见现代用法自行编写，不复制辞典例句，不收录全部义项，也不提供未经核对的典故年代或拼音。答后“查词典”链接访问相应[汉典词条](https://www.zdic.net/)，需要网络；游戏本身离线可玩。常用义辨析参考汉典，以及教育部《成语典》的[守株待兔](https://dict.idioms.moe.edu.tw/idiomView.jsp?ID=-39)、[水滴石穿](https://dict.idioms.moe.edu.tw/idiomView.jsp?ID=-180)、[不耻下问](https://dict.idioms.moe.edu.tw/idiomView.jsp?ID=-168)等条目。本游戏为语言练习，不代替完整辞典。

## 资源与保存

index.html为公共页面骨架；script.js为出题、提示、计分与回顾；style.css只承载题面与选字；logo.svg为本地书册铅笔标识。base.css/interface.js/icons.js从根公共源同步，不直接修改副本。

本机保存设置、近期成语ID和各题型/题量的最佳分，不保存未完成局。存储失败降级当前页面内存，损坏设置恢复默认。新增词条需保持四字、唯一ID、唯一正确选项、干扰项语义明确，并检查长释义/长例句在短屏中的布局。验证范围见根TEST-REPORT.md，浏览器触屏模拟不等同真机。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
