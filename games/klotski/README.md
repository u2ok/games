# 华容道

直接打开 index.html，或由静态服务器托管。目录可独立复制，无外部运行依赖。

## 玩法与操作

4×5棋盘，拖动或选中木块后使用方向键移动。木块不能重叠或穿过其它木块。将最大的曹操木块移到下方中间出口即过关。每次移动一格计一步；支持撤销和下一步路线提示。

P 暂停/继续，Enter 开始/继续/下一关，Shift+Enter 重开。更多、失焦或隐藏页面自动暂停，关闭后手动继续。触屏取消会结束当前手势。

## 设置与存储

三档难度，下一局生效。localStorage 在本机保存设置、关卡进度与分难度/关卡纪录；失败回退页内内存。提示局不写独立解题纪录。

## 关卡、提示与实现范围

12关，经典横刀立马的116步最短解路径截取分级：轻松剩余6–28步，标准32–65步，挑战70–114步。每次单格移动计一步。路线提示优先搜索3.5万状态，预算不足时沿保存的真实回退路线继续，不宣称局中提示一定最短。方括号键或Enter切换木块，方向键移动；滑动动画尊重减少动态效果设置。

## 文件与验证

script.js 为独立规则，style.css 仅维护玩法舞台，logo.svg 为本地物件式图形；base.css、interface.js、icons.js 由根公共源同步。验证范围见根 TEST-REPORT.md，不等同真机和所有随机局通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
