# 数织

打开本目录index.html或静态托管即可运行。原生HTML/CSS/JavaScript，无构建、框架、ES6 Modules或远程资源；复制目录可独立使用。

## 规则与题目

行和列的数字按顺序表示连续填色段的长度，相邻两段之间至少隔一格。0表示整条线不填色。填对所有填色格、没有多余填色即可完成；正确的空白格可以保持未确定，不强制全部标空。行列提示在当前填色段满足时变色，只表示该线段长度符合，不单独证明整题已完成。

提供5×5、10×10、15×15三种尺寸。6个内置基础像素图案按尺寸缩放，再随机旋转、镜像。每个基础图案发布前/首次使用时经行列候选约束传播与回溯检查唯一解；超出验证预算不会被当作唯一解。旋转镜像保持唯一性，但对称变体可能重复，不宣称无限随机题库。

## 操作

左键点击/拖动使用当前工具；右键或Shift拖动标空。再次从同类格开始操作时擦除，整次拖动保持同一个目标状态，一次拖动计一次撤销。手机使用“填色模式/标空模式”按钮切换。触控取消或暂停时保存已经涂过的部分。

Tab聚焦棋盘，方向键移动光标，Enter/空格使用当前工具，X标空，Delete/Backspace擦除，Ctrl/Cmd+Z撤销。撤销不回退计时或辅助标志。

检查仅指出已填色/已标空格中的错误，不评价未确定格；提示揭示当前格或下一处未确定/错误格。使用检查或提示后本局不计最快纪录，撤销也不能恢复独立解题资格。

首次编辑开始计时，暂停不计时。最快纪录按棋盘尺寸独立保存，完成时即时刷新；尺寸设置下一局生效，重新开始会重新随机选题。

P暂停/继续；Enter在准备/暂停/结束时开始/继续/再玩；Shift+Enter重开。设置、失焦和页面隐藏自动暂停，回来后手动继续。音效默认关闭；设置、纪录本机保存，存储失败回退内存。

## 界面、文件与验证

沿用公共PC右侧信息面板和手机顶部信息卡，填图工具与暂停/重开分组。提示随棋盘调整字号，行列提示留白一致，填色格保持方形。大尺寸在小屏交叉格较密，手机优先5×5。

index.html为入口；script.js包含线段、解计数、题目、拖涂和计时；style.css仅棋盘/提示/必要输入区；logo.svg为本地物件标识；base.css、interface.js、icons.js是公共源独立副本。独立复制后大厅链接按需调整。

遵循[统一规范](../../GAME-STANDARD.md)，验证范围见[测试记录](../../TEST-REPORT.md)。模拟DOM和浏览器视口测试不等同真机拖涂或全部图案手工通关。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
