# 塔防守卫

直接打开 index.html，可独立复制本目录运行，无运行依赖。

## 玩法

在固定路线旁的草地建塔，每关守住十波敌人，共六关。开始后10秒自动迎来首波；每波全部处理后休整6–8秒，再自动开始下一波。进攻中不会叠加波次。城堡生命耗尽失败，第十波全部处理后且城堡仍存活即获胜。

- 箭塔60金币：快射单体，射程145；炮塔100金币：射程130、75单位爆炸范围；冰塔80金币：射程125，命中减速50%，持续2秒，重复命中刷新时间。
- 各塔最高三级，每级增加基础伤害75%、射程12。升级费用为基础造价×(0.7+当前等级×0.35)，四舍五入。出售返还累计投入的70%，向下取整。
- 敌人有普通、快速、护甲和首领。护甲每次减伤5，最低仍受1伤害；第5、10波最后一只是首领，王城决战第10波额外增加一名首领，漏过扣4生命，其余扣1。
- 击败敌人赚金币，每波结束额外奖励30+波次×5。轻松/标准/挑战分别初始240/220/200金币、25/20/15生命，敌人生命倍率0.8/1/1.3。
- 塔自动优先攻击射程内最靠近出口的敌人。炮塔伤害敌人一次，冰塔减速不叠乘。道路不可建塔，建塔不改变路线。

首次只解锁第一关，通关解锁下一关；在更多菜单或PC侧栏选择已解锁关卡，切换会清空当前局并回到准备页。胜利遮罩可进入下一关，最后一关完成后可重玩；外部重新开始始终重玩当前关。记录按关卡与难度隔离，旧版纪录仅兼容读取到第一关。最近选择的关卡也会保存。各关生命倍率与难度倍率相乘，金币/生命在基础难度数值上增加各关相对第一关的差值。

## 操作与设置

先开始游戏，再选择塔型并点击草地建塔；点击已有塔选择，使用升级、出售按钮。方向键移动光标，回车建造；1/2/3选择箭塔/炮塔/冰塔，U升级、X出售、P暂停/继续，Enter开始/继续，Shift+Enter重新开始。手机使用相同的点击操作。为建造输入保留空间，移动摘要默认折叠，可手动展开查看完整状态。

打开更多、设置、切换页面或失焦会暂停，关闭后手动继续。难度新一局生效，音效即时生效。设置与按难度隔离的最佳已守波次保存在本机；存储不可用时退化为页面内保存。重新开始清空本局塔、敌人、金币与进攻状态。

## 文件与验证范围

index.html为公共骨架，script.js实现经济、战斗和绘制，style.css只定义棋盘及建造输入，logo.svg为本地城堡物件图。../../shared/base.css、../../shared/interface.js、../../shared/icons.js由根目录同步维护。

规则采用固定步进与真实折线路程，不使用寻路改道；没有联网、存档续局或加速功能。画面使用单一requestAnimationFrame循环，固定装饰避免闪烁；步行、转向、后坐、弹道和粒子按游戏时间推进，暂停时冻结。测试证据和浏览器视口覆盖见根 TEST-REPORT.md；浏览器模拟不等同真机测试。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
