# 黑白棋

打开本目录index.html或静态托管即可运行，原生HTML/CSS/JavaScript，无构建和外部依赖。

## 规则

采用8×8奥赛罗开局，中央黑白各两枚，黑棋先行。每步必须以新棋子和已有己方棋子，从横、竖或斜向夹住至少一枚连续对方棋子，所有被夹棋子同时翻转。不能主动放弃有合法落点的回合；无合法落点时自动停着，让对方继续。双方都不能落子时即结束（棋盘不一定填满），实际棋子较多者胜，数量相同为和棋。不将剩余空格额外计给胜方。

规则参考：[世界奥赛罗联合会](https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english)。

## 操作与模式

点击/轻触圆点位置落子；Tab聚焦棋盘，方向键移动蓝色光标，Enter/空格落子。橙点标记最后落子。

默认人机对战，玩家执黑、电脑执白；双人模式在同一设备轮流下棋。人机悔棋撤回至玩家上一手之前（包括电脑连续落子的情况），双人撤回一手；终局后不允许悔棋。切换模式开启新一局，胜局按模式和棋色分别保存。

电脑轻松档随机合法落子；标准搜索3层，挑战搜索4层，考虑角位、危险角邻格、行动力及后期棋子数，单次节点预算分别4000/12000；属于有限搜索，不保证最优。难度新一局生效，暂停取消电脑回调，继续重新安排，重开与模式切换使旧回调失效。

P暂停/继续，Enter在准备/暂停/结束时开始/继续/再玩，Shift+Enter重新开始。失焦、页面隐藏和打开设置自动暂停，回来后手动继续。设置用原生下拉，音效默认关闭，设置/胜局本地保存；存储失败回退内存。

## 文件与验证

index.html为入口，script.js包含规则和人机算法，style.css仅含棋盘及棋子样式，logo.svg为本地物件标识。../../shared/base.css、../../shared/interface.js、../../shared/icons.js是公共独立副本。复制本目录可离线运行，返回大厅链接可自行调整。

遵循[统一规范](../../GAME-STANDARD.md)，测试范围见[测试记录](../../TEST-REPORT.md)。浏览器视口模拟不等同真机测试。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
