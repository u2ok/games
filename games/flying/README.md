# 飞行棋

直接打开index.html，或由静态服务器托管；目录可独立复制，无外部运行依赖。

## 快速上手

1. 点左上骰子区的骰子或下方“掷骰子”。
2. 看摇骰动画和最终点数；6点可从机场起飞。
3. 点发光飞机或下方亮起的编号按钮移动。先归航四架获胜。

参考实体飞行棋的分格与十字终点结构，52格跑道采用38×38逻辑格距，飞机、编号和叠机偏移均限制在格内。左下红机场、右上蓝机场，左上骰子区、右下提示区。六面本地SVG组成CSS立体骰子，可见多个骰面，单次抛起翻滚、逐渐减速、轻微落地回弹、柔和阴影起伏，落定正面与结果一致。姿态由游戏时钟直接计算，不使用独立CSS动画或过渡，因此暂停与结果切换不会抢占旋转状态；相同点数连续出现也会完整重掷。抛起幅度按骰子尺寸适配，减少动态效果时直接显示结果朝向，不翻滚。机场、起点、方向箭头和终点有明确标识；归航计数显示为已到达/4。摇骰约0.95秒，结果至少停留0.9秒再进入选机或换回合，点数保留到下一次摇骰。飞机沿格子按路径实际距离连续前进，整体缓入缓出、转弯提前平滑转向，不逐格跳动；起飞渐变尺寸、尾迹与落点光圈增强动感。碰机时先保留敌机原位置，待己方落定后播放返回机场过渡，规则仍只结算一次。棋盘使用圆角跑道格、柔和分区、带机舱与编号的飞机，叠机在格内分开排布；移动期间仍显示正在飞行一方，落定后才显示下一方回合。渲染使用单一requestAnimationFrame时钟，暂停冻结所有飞行/落点/返回动画，重开清理。减少动态效果偏好下关闭晃动、缩短动画，但保留结果停留。

## 玩法

双人简化飞行棋，每方4架。掷6起飞并获得额外回合；连续三个6结束回合。沿52格公共航道前进，同色格可跳4格，进度12可飞到24（先检查直达飞行，再检查跳跃后飞行，单次结算）；进度52进入6格归航道，超过终点57会反弹。公共起点每13格一处为安全格，其余格落到敌机上将其送回机场。同色可叠放，四架先归航获胜。点击骰子或掷骰按钮再点飞机，空格掷骰、数字1–4选飞机。人机红方先行，电脑只选合法飞机，标准/挑战优先推进；非四人实体棋全规则版本。

## 操作与设置

鼠标/触屏按界面操作；P暂停/继续，Enter开始/继续/下一关，Shift+Enter重开。失焦、隐藏或打开更多自动暂停，手动恢复。设置在下一局生效。

## 数据与资源

本机localStorage保存设置与对战模式，不保存进行中的棋局，失败回退当前页内存，不上传数据。script.js为独立规则；style.css只维护棋盘；logo.svg为本地SVG物件图形；../../shared/base.css、../../shared/interface.js、../../shared/icons.js由页面直接引用根公共源。

## 已知范围与限制

这是双人简化规则，使用15×15十字方格公共航路与两条归航路，不是四人标准十字棋盘。安全格为航路每13格；6点连掷，连续三个6结束回合。电脑为有限启发式，不保证最优。
