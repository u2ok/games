# 中国象棋

直接打开 `index.html`，无需构建、ES6 Modules、网络或外部资源。

## 对弈

默认人机对弈，玩家执红先行、电脑执黑；可切换本机双人，红黑轮流行棋。点击棋子查看合法落点，再点击落点走棋。键盘聚焦棋盘后，方向键移动光标，Enter/空格确认。

支持车直行、炮隔一子吃子、马腿、象眼和象不过河、士仕与将帅九宫、兵卒过河、将帅不得照面。禁止走出使己方被将军的着法。无合法着法一方判负，将死和困毙均适用。

## 翻棋（4×8暗棋）

在“玩法”中选择“翻棋”，重新开始后生效；仍可选择人机或本机双人。32枚标准象棋子随机盖放，棋盘横置为8列4行。玩家一先翻任意一枚，首枚颜色属于玩家一（人机时是你），另一颜色属于玩家二或电脑。翻一枚、走一步或吃一子都消耗一个回合。

- 明子只能向上下左右走一格到空位，不能跨边或斜走。暗子必须先翻，不能直接吃掉。
- 普通吃子需相邻，等级为将/帅、士/仕、象/相、车、马、炮、兵/卒；高等级可吃低等级，同级可互吃。
- 兵/卒可以吃将/帅，将/帅不能吃兵/卒。
- 炮吃子必须同一行或列、隔恰好一枚棋子（明暗均可作炮架），可以吃任意等级的明子；不能相邻吃子。炮不吃子时也只走一格。
- 不使用明棋的九宫、象眼、马腿、过河兵、将军或将帅照面限制。
- 吃尽对手棋子获胜。全盘翻开后，对方没有合法走法也判负；还有暗子就仍能翻棋，不提前判困。
- 相同公开局面及行棋方三次出现，或80手没有吃子/翻子，判和；吃子或翻子会清零无进展计数。

点击暗子直接翻开，点击己方明子后显示合法目标，再点击目标移动或吃子。键盘方向键选格，Enter/空格确认。人机悔棋撤回一轮，电脑未走时只撤回刚翻/走的一手；双人撤回一手，翻子状态和首次定色也会恢复。结束后不可悔棋。

电脑的输入只有公开明子、空位和暗子位置，不读取暗子的身份；翻子位置按公开邻域选择，三档增加可见棋子的搜索深度，不保证专业水平。明棋和翻棋的胜局按人机/双人分别保存，不混用；翻棋的两项胜局对应玩家一/你与玩家二/电脑，不随定到红黑颜色交换。

## 休闲规则边界

同一棋子布局和行棋方出现三次，或连续 120 手（每方走一步算一手）无吃子，自动判和。没有实现竞赛规则的长将、长捉责任判定、裁判罚则或计时。棋子提示仅显示合法走法，不保证最佳着法。

## 电脑、悔棋与保存

电脑提供轻松、标准、进阶三档，目标主搜索深度为2、3、4层，叶节点额外延伸最多3层吃子交换；应将节点会搜索合法解将，无合法走法即判负。采用Alpha-Beta、迭代加深、置换表及优先着法排序，按棋子几何生成候选后仍使用统一规则校验；评价考虑子力、车炮通路、马的活动性、兵卒过河及残局推进、将帅位置和士象保护，并惩罚重复局面。计算预算为约180/450/850ms和4000/16000/36000节点；只采用最后完整一轮搜索结果，实际深度依设备性能和局面复杂度而定。单次计算在主线程同步完成，慢设备可能有短暂停顿，不等同于专业象棋引擎。

没有固定开局路线。电脑在接近最佳评价的着法内随机选择，三档容差为40、18、8个估值单位；进阶变化范围更小，避免为变化而选择明显劣着。相同开局可能出现不同应对；若只有唯一明显优势着法，仍可能走相同棋。难度在设置中选择，新一局生效。

人机悔棋撤回最近一轮；电脑尚未走时只撤回玩家刚走的一手。双人悔棋撤回一手。终局不可悔棋，避免重复统计胜局。

打开设置、菜单、页面隐藏或失焦时暂停，并取消尚未执行的电脑落子；继续时重新安排。模式切换和重开也取消电脑回调。模式、设置及红黑胜局保存在本机；两种模式分别统计，和棋不计胜局。存储失败时降级内存。

## 独立文件

明棋和翻棋共用木框/木纹、奶油色棋面、红黑楷体字、圆形双线边缘、厚度与阴影的绘制函数；盖面使用同材质木色雕纹，不包含隐藏棋子身份。两种玩法统一选中圆环、合法空位点、可吃虚线圈、键盘游标及上一步痕迹，保留各自格局与规则。

棋盘提供木纹边框、楚河汉界、九宫线、兵炮位标记和坐标。松绿圆环为选中棋子，绿色点为合法空位，红色虚线圆为可吃棋子，红色实线圆为正在被将军的将帅；虚线连接表示上一步。键盘聚焦时才显示方形游标。

`../../game-base.css`、`../../game-interface.js` 为根目录共享基础入口，`style.css` 为工具栏样式，`script.js` 实现规则、对弈、搜索、保存与 Canvas 绘制。部署时须携带根公共文件并保留相对路径，返回大厅地址按目录调整。Canvas 提供状态与棋盘键盘输入，但不提供完整读屏棋盘。历史浏览器抽查见合集测试报告；不代表当前版本所有状态或真实设备均已验收。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`../../game-base.css`、`../../game-interface.js` 直接引用根目录公共源，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；仅复制本目录不能完整运行，需携带根公共文件并保留相对路径。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
