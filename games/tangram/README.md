# 七巧板

把七块彩色拼板移入上方目标，完整覆盖轮廓且互不重叠即可过关。每块都要用上；同样大小的三角形可以互换，不强制照参考编号拼。

## 操作

- 鼠标或手指拖动拼块；先选中，再用“旋转”每次转45°。
- 只有7号平行四边形需要“翻面”。接近参考位置且角度正确时自动吸附；也接受其他合法拼法。
- 下拉框或数字键1–7选块；方向键移动8个逻辑像素，Shift+方向键微调2像素。R旋转，Shift+R反向旋转，F翻面。
- “撤销”恢复上一步移动、旋转或翻面。“提示”显示所选块的一种参考位置4秒，本局不计最快纪录。
- 公共快捷键P暂停/继续，Enter开始/继续，Shift+Enter重新开始。输入框和下拉框操作时不触发游戏快捷键。

## 关卡和辅助

16幅固定且不同的连通轮廓，从方形入门，再挑战折线轮廓。标准七块面积比例为4:4:2:1:1:2:2；全部关卡使用相同七块，依次解锁。

设置有“引导”（显示分块）、“标准”（只显示轮廓）、“挑战”（更小吸附范围）。设置在新局生效。最快秒数按关卡和辅助程度分别保存；解锁进度共用。使用提示仍可解锁下一关。

## 画面与运行

沿用公共导航、信息面板和操作区。私有画面采用柔和彩色拼板、描边阴影、选中虚线、旋转/翻面/吸附过渡和通关碎彩；系统开启减少动态效果时取消这些运动过渡。旋转或吸附动画期间暂不接受下一次移动，避免状态冲突。

暂停会冻结计时及拼块动画；拖动途中暂停、触摸取消或窗口尺寸改变时，恢复本次拖动前的位置。离开窗口后自动暂停，返回需手动继续。

直接打开本目录index.html，或复制整个目录独立运行；无外部运行依赖。存储受限时进度仅保留在当前页面，界面会显示提示。关卡文件levels.js为本地固定数据；判定采用多边形裁剪计算覆盖与重叠，允许小于一个逻辑像素平方的浮点误差。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。shared/landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用shared/base.css、shared/interface.js、shared/icons.js、shared/landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
