# 五子棋

直接打开 `index.html` 或静态托管运行；原生 HTML/CSS/JavaScript，无构建工具、ES6 Modules 或网络资源。

## 规则与操作

15×15 棋盘，黑棋先行，双方轮流在空交叉点落子。横、竖或斜线形成五枚及以上同色棋子获胜，满盘无胜方则和棋。采用自由规则，不含三三、四四或长连禁手。

点击/轻触交叉点落子；键盘方向键移动绿色光标，聚焦棋盘后用 Enter/空格落子。橙点标记最后一手，获胜时显示连线。

## 模式、难度与悔棋

- 人机对战默认开启，玩家执黑、电脑执白；轻松模式从评分较好的候选点中随机选择，标准模式取最高评分。两档均优先获胜或阻止对手的一步五连。属于启发式电脑，不保证最优落子。
- 双人对弈由同一设备两人轮流落子。切换模式开始新一局，胜局按模式和棋色分别记录。
- 人机悔棋撤回最近的电脑与玩家各一手；电脑尚在思考时只撤回玩家一手。双人每次撤回一手。已结束的棋局不支持悔棋，避免重复计入胜局。
- 难度新一局生效，音效默认关闭。设置与胜局保存在本机，存储失败时回退内存。
- 暂停会取消待执行的电脑落子，继续后重新安排。重开与切换模式会使旧回调失效。

## 统一界面

`base.css` 与 `interface.js` 随游戏独立保存，`style.css` 仅定义专属区域。桌面左右布局，手机模式和配置位于“更多”弹窗，悔棋保留在棋盘下方。复制目录可运行，返回大厅链接应根据位置调整。


## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，竖屏局内操作保留在游戏区下方，横屏集中右栏。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`base.css`、`interface.js` 为公共源的独立副本，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；复制目录独立运行不依赖这些文档链接。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。本地landscape.css由根同步脚本生成，不直接编辑；验证范围见根TEST-REPORT.md。
