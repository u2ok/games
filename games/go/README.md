# 围棋

打开本目录index.html或通过静态服务器访问即可运行。无框架、构建工具、ES6 Modules或外部运行依赖；复制本目录可独立使用。

## 规则范围

支持9路、13路和19路，默认9路。采用中国式面积计分的休闲规则：黑先、禁自杀、位置超级劫（除停着外，落子后的整个盘面不得与本局已有盘面相同），白方固定贴7.5目。无让子、时限及赛事裁判机制，不宣称完整复现某一版赛事规则。

棋子上下左右相邻构成棋块，邻接空点为气。落子后先提走无气的对方棋块，再检查己方是否有气；允许通过提子使原本无气的位置合法。棋盘边界不连通、斜向不连通。

停一手永远是合法回合，不按重复局面禁着。连续两次停着后进入数子阶段。点击有棋子的交叉点可整块标记/取消死子，红叉和淡色显示标记。棋盘原始棋子仍保留；双方就死子达成共识后点击确认结果。有人不同意时点击继续对局，恢复原盘面与行棋方并清除死子标记/连续停着计数。

最终面积＝存活棋子＋仅接触己方的连通空点；双方共同接触或完全无边界颜色的空区不计分。移除标记死子后再计算，白方额外加7.5目，得分较多者胜。提子数仅作过程参考，不再重复计分。不自动判定复杂死活、双活或劫争，需双方确认或继续下至争议消除。

参考：[英国围棋协会规则比较](https://www.britgo.org/rules/compare.html)及其[规则介绍](https://www.britgo.org/intro/intro2.html)。本游戏明确采用位置超级劫及固定贴目，不混用日本目数/俘子计分。

## 操作、模式与电脑

点击/轻触交叉点落子；Tab聚焦棋盘，方向键移动蓝色光标，Enter/空格落子。橙点是最后落子。数子时同样可用键盘切换死子标记。

人机模式玩家执黑，电脑执白；双人模式同设备轮流行棋。模式切换立即新局。电脑三档均只下合法棋，避免填明显的己方眼位；轻松在前12个候选内随机，标准评估提子、救棋、打吃与气，挑战对前8个候选再检查对手即时提子反击。这是休闲启发式对手，不具备专业棋力或完整死活搜索，也不保证最优。

双人悔棋撤回一手；人机回到玩家上一手之前。提子、停着和超级劫历史同步回退。终局后不支持悔棋。认输需连续点击两次；人机始终视为玩家执黑认输，双人视为当前行棋方认输。

P暂停/继续；Enter准备/暂停/终局时开始/继续/再玩；Shift+Enter重新开始。打开设置、失焦或页面隐藏自动暂停并取消电脑回调，回来后手动继续。设置使用原生下拉，路数与电脑难度下一局生效，音效默认关闭。设置、模式与分模式/路数/棋色胜局本机保存；存储不可用时退回内存。

## 布局、文件与验证

沿用公共PC侧栏、手机顶部信息与下方操作栏。棋盘默认方形，19路在小屏交叉点较密，9路更适合手机休闲操作。

index.html为入口；script.js为规则、计分、电脑和状态；style.css仅棋盘、交叉点及棋子样式；logo.svg为本地物件标识。base.css、interface.js、icons.js为公共副本，禁止在本目录直接维护。独立复制后返回大厅链接按需调整。
