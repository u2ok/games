# 拼图

将下方凹凸拼块拖入上方画框，拼出完整的风景。直接打开index.html，或复制整个目录独立运行；不需要联网或构建。

## 图案与难度

提供三幅本地原创SVG插画：林间小屋、海岸灯塔、星空营地。可选6块（3×2）、12块（4×3）、20块（5×4），设置在新局生效。各难度只改变分块，图案均完整显示，不拉伸插画。

拼块使用互补的曲线凹凸口，外框边缘为直线；无需旋转。拖动时拼块放大到画框中的实际尺寸，松手接近正确位置则吸附锁定，其他位置会回到托盘。只有正确吸附才增加归位计数，没有步数惩罚。

托盘每组最多六块，整张卡片都可拾取拼块；每组用1–6标记当前组的位置，不表示目标格编号。“换一组”循环查看仍有未放拼块的组；完成一组后自动切到下一组。

## 辅助与完成

- “参考图”淡入显示完整画面3秒，期间继续计时，也可提前收起；可以自由查看。
- “位置提示”显示选中拼块的目标轮廓2.5秒，不自动放置；使用后本局为辅助局，不计最快纪录。
- 全部归位后显示完整插画和完成碎彩，结算用时。最快秒数按图案和难度分别保存，至少记1秒。
- 完成后“欣赏成图”收起遮罩，显示完整画面；“返回成绩”恢复结算页。“下一幅风景”切到下一场景，保留所选难度。

## 输入与暂停

鼠标或手指按住托盘拼块，拖到目标松手。只有首个指针有效，其他手指不能抢占。触摸取消、捕获丢失、窗口尺寸改变或拖动中暂停会把拼块还回托盘，不会误放。

数字1–6选当前组拼块，PageUp/PageDown换组。画布获得焦点后，Enter把所选拼块拿到画框中心，方向键移动，每次12个逻辑像素；Shift+方向键精调4像素。Enter放下，Escape取消。也可直接用方向键开始移动。编辑区、下拉框、输入法与组合键不触发操作。

公共快捷键P暂停/继续，Enter准备时开始/暂停时继续，Shift+Enter重开。打开更多、失焦或隐藏页面自动暂停，返回后手动继续；暂停冻结吸附/回弹、参考图/提示计时、完成动画与用时，未放下的拖动或键盘移动则取消。已进入吸附动画的拼块会在继续后完成结算。

## 美术与资源

forest.svg/coast.svg/night.svg为手工绘制的原创场景，不使用远程图片、商业角色或字体图标；logo.svg为凹凸拼块与小屋物件标识。script.js生成互补路径，按路径裁剪同一幅场景，统一600×720逻辑坐标用于绘图与触控换算。托盘、画框和回弹动作使用同一套中心坐标。

所有动画由单一requestAnimationFrame循环推进，重新开始清除待完成动作和粒子。系统偏好减少动态效果时取消位移过渡、参考图淡化与粒子，保留必要的最终放置反馈。图片未加载时禁止开始并显示反馈；文件缺失时提示检查本地资源。

style.css仅规定拼图画布比例和拖动手势；导航、按钮、信息卡、菜单与快捷键沿用公共源，../../game-base.css/../../game-interface.js/../../game-icons.js通过根sync-interface.py同步。

## 保存与验证范围

保存图案/难度/音效设置、分图分难度最快纪录和导航最近游玩，不保存未完成拼图。存储失败降级当前页面内存，损坏设置恢复默认。

验证证据见根TEST-REPORT.md。程序化规则拼合不等同人工通关，浏览器触摸模拟不等同真机。最小手机视口为320×568；托盘卡片是触控区域，拼块图案本身可能小于卡片。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
