# 跳一跳

按住蓄力，松手自动朝下一座浮岛跳跃，争取更高分。直接打开本目录index.html，或复制整个目录后独立运行；不需要联网、构建或安装依赖。

## 规则与操作

- 按住画面或下方“按住蓄力”按钮；也可按住空格键。松手起跳，不需要手动选择方向。
- 蓄力从0到1.2秒，距离由40线性增加到300个逻辑像素。达到上限后保持最大力度，不会自动跳，也不因继续按住而更远。
- 角色脚底落在下一平台的椭圆台面内算成功，普通落台得1分。落在归一化椭圆半径23%以内算正中，连续正中依次奖励2、4、6、8分，之后每跳最高8分。这是本跳总分，不与1分重复累加。
- 落回原平台可以再试，不计分并打断正中连击；落到空处则跌落结束。提示会指出距离不够或跳得过远。
- 成功后镜头移动到新的平台对，完成移动后可以继续蓄力。平台随机向左上或右上生成，没有关卡终点。
- P暂停/继续，Enter开始/继续/再玩，Shift+Enter重开。输入框、下拉框、输入法和组合键不触发蓄力；空格长按只启动一次，松手只起跳一次。

## 难度、动画与暂停

轻松：大平台，蓄力时显示预计落点；标准：中等平台，无落点辅助；挑战：小平台，无落点辅助。难度在新局生效，最佳分按难度独立保存。所有玩法计分一致。

角色有蓄力压缩、弧线腾空、围巾与拖尾，落台有回弹、波纹和碎彩。平台使用花园、木台、糖果、礼物四种材质，镜头平稳跟随。系统选择减少动态效果时去掉粒子、拖尾、摆动和回弹，缩小跳跃弧线并缩短镜头过渡；保留判断落台所需的位移。

打开菜单、失焦或页面隐藏时自动暂停，关闭后手动继续。暂停取消未松手的蓄力，恢复后需要重新按住；已经起跳的动画、镜头和特效会冻结。触摸取消、指针捕获丢失或窗口尺寸改变时取消蓄力，不会起跳。只响应首个输入，第二根手指不会抢占正在蓄力的指针。

## 资源、保存与限制

Canvas采用600×600逻辑画布，碰撞使用平台椭圆，与绘制相同坐标。腾空高度只用于绘制，不改动地面落点判定。暂停、计时、跳跃及特效共用一个requestAnimationFrame循环；保存最佳分与设置，未完成局不存档。存储损坏恢复默认，存储不可用时回退当前页面内存。

index.html为公共骨架；script.js为规则、输入与Canvas绘制；style.css仅补充蓄力触控；logo.svg为本地角色与浮岛Logo。base.css/interface.js/icons.js从根公共源同步维护。

这是原创浮岛美术与单键跳跃玩法，不使用商业游戏角色、图片或音频；无联网排名。验证证据见根TEST-REPORT.md，浏览器触摸模拟不等同真机验证。
