# 拔针救球

直接打开index.html即可运行，也支持普通静态托管。复制本目录仍可独立游玩，无外部运行依赖。

## 规则与操作

24关交替安排六类机关：分仓汇流、逐仓接力、逆向接力、左侧供色、右侧供色、窄仓分批。关卡改变通道连接、供色入口、仓容量与源球配置，灰球必须在入杯前染色；溢仓、灰球入杯或球进危险槽均失败。轻松为双支路且汇流仓容量6；标准前12关双支路、后12关三支路，汇流容量5；挑战为三支路、汇流容量4。窄仓关有一仓容量仅够单个源仓的一批球，必须规划先后放流。各仓实时显示当前球数/容量。点击针柄拔针，方向键选针、回车拔针；已开针持续放流。撤销恢复上次拔针前状态，顺序提示根据当前局面搜索安全解，辅助局不计最佳。

- 分仓汇流：各支路染色后分批汇流。
- 逐仓接力、逆向接力：混色仓依次串联，先处理下游积球，避免接力时溢出。
- 左侧供色、右侧供色：彩球绕过支路混色仓直达公共仓，灰球必须在公共仓与它汇合。
- 窄仓分批：局部仓装不下一整组灰球和彩球，先把一批送入下游，利用下游染色再排空。

## 设置、记录与生命周期

三档难度在重新开始后生效。P暂停/继续，Enter准备或终局时开始/再玩，Shift+Enter重开。打开设置、页面隐藏或失焦时暂停，关闭后需手动继续。触摸取消及窗口尺寸改变会取消未完成输入，暂停清除按键状态并冻结动画时钟。减少动态效果偏好关闭装饰粒子；必要的运动轨迹仍保留。

v3规则的最佳得分与完成进度独立保存，保留旧数据但不沿用旧通关成绩。最高得分按难度及关卡独立保存。谜题通关分=max(10,1000-完整秒数×2-操作次数×5)；叠楼、接水果、套圈及节奏记忆等在界面结算中说明本局成绩。使用辅助不计最佳。localStorage损坏时恢复默认，写入失败在当前页面保留纪录。共24关，所有关卡自由选择；当前关和完成进度保存在本机。

## 资源与限制

script.js为独立规则及本地Canvas物件绘制；logo.svg用于标题和导航卡片。../../game-base.css/../../game-interface.js/../../game-icons.js从根公共源同步，私有CSS仅定义输入手势。画布与命中统一600×600逻辑坐标。玻璃容器和导管采用本地Canvas绘制，拉针抽出、球体错峰流动、落底回弹与灰球染色共用游戏时钟；各仓按真实容量布置球位，导管、针位、球体轨迹和命中使用同一几何数据。单一requestAnimationFrame，无业务setTimeout或异步动画回调。

物理类为面向玩法的近似模拟，不宣称精确现实物理；离线单机，不依赖远程图片或音频。测试范围与浏览器模拟/真机区别见根TEST-REPORT.md。

移动横屏：触屏设备横屏、宽≤1200px且高≤480px时采用左棋盘、右导航/信息/操作；导航、普通操作和专用输入均复用竖屏移动规则，按可用宽度自然换行。PC与竖屏沿用原布局。game-landscape.css为根目录唯一共享生成资源，不直接编辑；验证范围见根TEST-REPORT.md。

公共资源：本游戏直接引用根game-base.css、game-interface.js、game-icons.js、game-landscape.css；目录内不保存公共副本。运行或部署须保留项目结构，单独复制游戏目录不再完整可用。详见根README.md。
