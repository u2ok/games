# 2048

双击本目录 `index.html` 即可运行，也可静态托管，无构建工具、ES6 Modules 或网络依赖。

## 规则与操作

方向键 / WASD 或在棋盘滑动。每次移动仅合并一次相邻同值方块；无变化不生成新方块。合出 2048 后可继续挑战。

## 宫廷版

桌面在右侧面板切换“经典数字 / 宫廷晋升”，手机在顶部游戏菜单中切换。切换会开始新一局；模式选择保存在本机。两种模式的最佳分数分别保存，经典版原纪录不变。

宫廷版沿用 4×4 和相同数值合并规则，以位阶替代主数字显示，附带小号数值供对照：

宫女（2）→ 答应（4）→ 常在（8）→ 贵人（16）→ 嫔（32）→ 妃（64）→ 贵妃（128）→ 皇贵妃（256）→ 皇后（512）→ 皇太后（1024）→ 太皇太后（2048）。

合出太皇太后即达成目标，可继续合并为太皇太后 2星、3星等。位阶顺序为游戏主题设定。玩法说明中可查看晋升路线。

## 通用功能与保存

- 新一局、暂停和继续；页面失焦、隐藏或打开设置时自动暂停。
- 音效默认关闭，使用 Web Audio 合成，无外部音频。
- 设置与最佳记录保存在本机，存储不可用时退回内存并提示。
- 键盘按钮均有焦点样式，手机适配；Canvas 游戏不提供完整非视觉操作。

## 文件

`index.html` 为语义化页面，`base.css`、`interface.js` 为公共副本，`style.css` 为玩法专属样式，`script.js` 为独立闭包中的全部逻辑。复制文件夹可独立运行，返回导航链接需根据位置调整。

现代浏览器运行；本地文件的存储隔离依浏览器而异，建议通过静态服务访问以共享最近玩过。

## 统一界面

`base.css` 为随本游戏保存的统一设计基础，`style.css` 仅包含专属棋盘样式。桌面左棋盘右面板；850px 以下切为竖向，设置使用底部面板。页面、操作、状态和说明使用一致的设计令牌。



## 公共界面与快捷键

P 暂停／继续；Enter 在准备、暂停或终局时开始／继续／再玩；Shift＋Enter 重新开始。进行中的 Enter 保留本游戏原有操作；输入框、设置和菜单弹层内不触发通用快捷键。

公共界面与响应式约定见 [统一规范](../../GAME-STANDARD.md)。PC 配置在顶部；手机通过顶部或底部“更多”调整模式和设置、选择关卡及查看规则，局内操作保留在游戏区下方。

本地 `logo.svg` 同时用于标题与浏览器标签图标。`base.css`、`interface.js` 为公共源的独立副本，不直接编辑。合集内维护要求见 [统一规范](../../GAME-STANDARD.md)，历史验证范围见 [测试记录](../../TEST-REPORT.md)；复制目录独立运行不依赖这些文档链接。
